# Mathsemble 模板说明

本目录模板适用于 **0.1.15 开发版**，使用 `?{答案}`／`!{答案}` 和五级题目标题。规范以 [Markdown 书写规范](../docs/MARKDOWN_SPEC.md) 为准；公开 v0.1.10 的旧答案语法与这些模板不兼容。

| --- | --- | --- |
| [讲义_五级题目标题.md](讲义_五级题目标题.md) | 可运行的最小示例，覆盖小问交替、答案／思路、选择／填空及六级题内标题 | 6 |
| [讲义【通用模板】.md](讲义【通用模板】.md) | 知识点、条件转化、题型归纳、课后练习的结构占位模板 | 10 |
| [考前复习讲义【模板】.md](考前复习讲义【模板】.md) | 集合、逻辑、二次不等式与最值的复习示例 | 8 |

普通讲义以合法 `##### 例1`、`##### 练习1` 等开始每道题，独立总结也使用 H5 或更高层级标题。单题卡、文件夹组卷以文件为一题，不要求卡片再添加 H5。

题卡采用插件实际读取的 `question_type`、`teaching_tier`、`knowledge_nodes`、`source` 字段。原有知识点、方法、章节文字及示例 ID 已保留；`chapter` 只是原章节名称，不替代 `chapter_id`。未知的章节 ID、节 ID、教学角色及题族关系保留 `null`，因此组卷审计仍会提示 `chapter_id`、`section_id`、`role` 缺失。应依据真实题库填写，不能为了消除提示编造数据。

复制题卡进入正式题库时必须替换示例 ID，并核实来源。复习讲义中的原稿“深圳中学期中真题”“期中真题”及定级均已标记待核实；本次没有核验原卷。解答题第二问已改为表格可确定的点处切线问题，原教学层级和方法标签需要再次确认。通用讲义仍有题干、答案、解析的占位文字，填写完整后才能用于课堂。

完整作答使用 `[!answer]-`，可选方法提示使用 `[!solution]-`。学生版默认为答案留白，思路默认隐藏且不留白；教师版默认显示两者。普通高亮保留强调用途，不得用它标注隐藏答案。

在仓库根目录运行 `node --test tests/templates.test.cjs`，可核对模板题数、题目边界、答案投影、元信息与清单链接。该检查直接读取 `src/plugin.js`；数学内容仍需人工审校。正式使用前，在独立 Obsidian 测试库检查学生／教师预览与 PDF 中的题目、公式、留白和分页。
