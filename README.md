# Mathsemble｜数课工坊

Mathsemble 是 Obsidian 桌面端数学教学插件，用一份 Markdown 制作讲义、题卡和试卷，预览并导出 A4 学生版／教师版 PDF、打印稿及 HTML。

**当前版本：[0.2.4](https://github.com/sunsimilarsun/Mathsemble/releases/tag/0.2.4)。** 在正式 0.2.3 基础上新增错误一键定位、条件抽题和预览编排，支持分区整体移动、课程与默认排版随方案保存；从编排预览 A4 无需先生成讲义文件。完整流程与保存范围见[产品设计](docs/PRODUCT_DESIGN.md)，版本说明和对应验证见 [0.2.4 说明](docs/RELEASE_NOTES_0.2.4.md)及[测试记录](docs/TESTING_0.2.4.md)。

## 选材与编排

1. 在命令面板执行 **打开选材与编排**，或点击侧栏“选材与编排”图标。
2. 设置题库和知识库目录（库内相对路径，每行一个），点击“应用目录并刷新”；模板、登记和输出目录默认不收录。
3. 在“内容筛选”设置常用条件，其他条件在“更多筛选”中展开；当前条件以标签显示，可逐项清除。结果与候选卡片直接预览正文开头，公式和图片自动渲染，无需点击；点击标题查看完整正文，收起预览返回列表。题卡知识标签可以关联到实际知识笔记；同名歧义保留提示。
4. 点击顶部“预览编排”或已选数量入口，连续查看已选知识、题目和分区。拖动手柄或上下箭头调整顺序，分区会连同所属题目和知识一起移动；直接编辑本次标题和例题／变式／训练角色。“更多”中提供指定位置、打开原文和移除。点击“添加分区”后填写标题。
5. 保存方案到 `Mathsemble/组题方案/`；“刷新素材”只重新读取内容，“接受来源更新”才接受方案引用的新版本，保留本次标题和角色。删除、重复 ID 或缺失来源不会被自动替换。
6. 点击顶部“预览 A4”，直接检查当前编排并导出 PDF／HTML，不新增 Markdown，也不自动保存方案。需要 Markdown 时，选择“方案操作 → 保存讲义副本”，保存到 `Mathsemble/讲义/`；每次保存新建文件，已有副本不自动改写。

**保存方案**保存讲义标题、顺序、来源引用、本次标题和角色、分区，以及课程信息和默认排版设置；正文仍保留在原笔记。方案保存状态与最近读取的来源状态分开显示；已保存不等于来源已更新或 A4 已检查通过。

选材页显示“内容筛选／选材与预览”两栏，窄分栏通过“筛选／选材”切换；排序和修改集中在独立的预览编排页。结果与候选均每行一道题，占满列表宽度；预览高度随内容增长，最长显示 320px，短题不留大块空白，长题可点击“查看全文”。界面跟随 Obsidian 的浅色或深色主题，标题、模式切换、保存和 A4 预览集中在顶部，已选数量入口同时区分题目、知识和分区。

知识正文按整篇加入，暂不提供小节截取、题型配额或自动修改知识标签。Markdown 笔记嵌入需先展开为正文，否则阻止生成以避免学生投影遗漏；图片按原文件位置重新解析。

### 预览编排

“预览编排”使用独立的宽幅单列界面，每项直接显示正文，长内容可在原位置展开。题号只统计题目；普通题目和知识按全部编排项指定位置，分区按分区序号指定位置。调整会同步到同一方案，保存与 A4 预览使用当前顺序；返回“选材”继续补题时保留筛选和候选状态，实际修改编排后需要重新生成候选。

一个分区包含分区标题及其后直到下一个分区之前的题目和知识。分区的上下箭头交换前后完整分区；拖到另一分区的标题或任意内容上，向下移动时放在目标分区之后，向上移动时放在目标分区之前。“更多”中可直接填写目标分区序号。空分区也可移动，首个分区之前的内容保持在开头；普通题目和知识仍按单项移动。“移除分区标题”仅移除标题，保留正文。

每项的工具集中在正文上方一行，标题和角色可直接编辑，其他操作收纳到“更多”。正文末尾按需显示“展开全文”：长内容、超宽内容或隐藏的答案／解析可展开查看，已完整显示的短内容不重复提供展开按钮。

标题和角色只修改本次方案。源文已变化、缺失或身份冲突时会显示提示，接受来源更新后再核对输出；不会静默替换来源。

### 临时 A4 预览

“预览 A4”使用打开时的编排与来源快照，不随原笔记自动更新。预览期间，所配置题库或知识库目录中的 Markdown 发生新增、修改、删除或改名，即使不是本次已选内容，也会保守地使旧预览失效并阻止继续导出。

点击“返回编排更新”回到原工作区，刷新素材、核对并按需接受来源更新，再重新打开 A4。返回不会恢复旧草稿、自动接受来源或保存方案；若原工作区已经关闭，需要重新打开方案。

临时预览的诊断指向原题卡或知识笔记；能可靠匹配时定位到行，否则打开对应文件。单独打开已保存的讲义副本时，按普通文档读取、重新读取和定位该副本，不追溯或汇总上游素材。

### 课程与排版

在“方案操作 → 课程与排版”中设置教师、学生、时间、学科、年级、课题与学习目标，以及默认外观、内容版本、留白和解析选项，再点击“保存方案”。下次从该方案预览 A4 时恢复这些设置。

课题默认跟随讲义标题；取消“课题跟随讲义标题”后可单独填写，也可主动留空。教师留空时使用“孙老师”。生成讲义写入 `titile`、`author` 等课程属性，不从任一题卡借用课程信息。

在 A4 界面调整后，点击“设置 → 应用到编排方案”，再返回工作区保存方案。本次调整不会自动回写；若编排已更换或修改，旧 A4 窗口会拒绝应用，需从当前方案重新打开。源题卡与已生成的讲义副本均不改写。

旧方案打开时只在内存补默认设置，显式保存后升级为格式 v2；旧版插件不能读取新保存的 v2 方案。

### 条件抽题

1. 在“题目”页设置知识点、题型、教学层次等筛选条件，填写抽题数量后生成候选。
2. 查看候选题，可预览、移除或重新抽取；生成候选不会改动现有编排。
3. 点击“加入编排”，重新核对来源后整批加入；继续手动排序、改本次角色或保存方案。

抽取覆盖全部符合条件的题目，排除编排中已有题和身份冲突项。数量不足或方案容量不足时显示实际可加入数量，不自动放宽筛选。筛选、扫描或编排变化后需重新生成候选；应用时发现源文变化则保留原编排并提示重新抽取。源题卡保持原样。

源码基线恢复与版本差异见 [0.2.0 开发基线](docs/BASELINE_0.2.0.md)。

本轮工程和宿主验证见 [外观测试记录](docs/TESTING_APPEARANCE_20261109.md)。知识属性历史验证见 [0.2.1 测试说明](docs/TESTING_0.2.1.md)，首版试用流程见 [0.2.0 测试说明](docs/TESTING_0.2.0.md)；各报告中的测试数字仅适用于当时的代码与环境。

## 快速使用

1. 打开并保存 Markdown，运行命令 **当前讲义：A4 排版与导出**。
2. 在原文、学生版、教师版之间切换，并通过工具栏的 **外观** 选择默认、双列或试听排版，核对题目范围、公式、图片和留白。
3. 选择保存当前版本 PDF、学生版和教师版 PDF 或保存 HTML；默认输出到库内 `ExamExports/`。保存 PDF 后可点击“打开已保存 PDF”，在系统阅读器中打印。

单题卡使用 **当前题卡：A4 排版与导出**；题卡文件夹使用 **当前文件夹：组卷与 A4 预览**，支持按题型或主知识点分组。文件夹最多扫描 200 个 Markdown 文件，单次最多组卷 100 题。

“重新排版”只重新渲染当前内容；普通文档的“重新读取源文”读取已保存的文件。从编排打开的临时 A4 使用“返回编排更新”，由用户刷新素材、核对来源后重新预览。单独打开讲义副本时，只读取和定位该副本。

### 排版外观

- **默认排版**：沿用 A4 单栏正文。直接打开文档时默认使用此项，从方案生成时使用方案保存的外观。
- **双列排版**：同一张 A4 从左栏排到右栏，再续到下一页；公式、图片、选项和学生留白按实际栏宽重新测量。支持 MathJax 4 的宿主中，长公式会按栏宽在合适的运算符处自动换行，保持正常字号；原文不变。`------` 仍跳到下一张纸的左栏。过宽且无法拆分的公式或表格会提示溢出，可切换回默认排版。
- **试听排版**：首页显示课程信息表、灰色“内容”栏，讲义正文排在下方框内；续页保留正文框。长公式按正文框实际宽度自动换行，长解答可继续分页。教师读取 `author`，缺失或空白时默认“孙老师”；课题名称仅读取 `titile`（按此拼写），不读取 `课题名称` 或 `title`。其他项目读取当前文档属性：`学生`、`上课时间`、`subject`、`年级`、`教学目标`；兼容 `student`、`class_time`、`学科`、`grade`、`学习目标` 等字段。目标列表逐行显示；除教师外，缺失、空值或“待补”留空，不用文件名补题目。可在 **试听信息** 中手动调整。

双列与试听会先展开打印副本中的折叠解答，再按实际缩进测量公式。超宽的行内分段条件／表格公式会改为独立公式块，允许单元内部换行；短公式保持行内，普通阅读视图的折叠状态不变。

外观与学生／教师版本独立选择，当前预览、保存 PDF、双版本 PDF 和保存 HTML 使用所选外观。从方案进入 A4 时恢复方案中的默认排版；调整后可显式应用回编排草稿并保存。直接打开文档时，外观使用默认值，课程信息读取文档属性，本次调整仅用于当前窗口。排版界面的修改不写入 Markdown。普通文档的“重新读取源文”更新未手动修改的信息，保留手动输入和主动清空的项目。双列及试听 HTML 保存为已分页的静态页面。

## 书写规则与模板

**唯一现行书写规范：[Markdown 规范](docs/MARKDOWN_SPEC.md)。** 本地配套模板维护在相邻 Markdown 内容库，入口为[模板清单](../../Markdown/数学教学/模板&规范/README.md)，可从[通用讲义模板](../../Markdown/数学教学/模板&规范/讲义【通用模板】.md)开始。生产模板不在本仓库内；更换设备时按实际内容库位置定位。

```markdown
# 二次函数专题

## 典型例题

##### 例1 最小值

函数 $f(x)=x^2-2x$ 的最小值为 ?{-1}。

> [!solution]- 解析
> 因为 $f(x)=(x-1)^2-1$，且 $(x-1)^2\ge 0$，所以当 $x=1$ 时，最小值为 $-1$。

##### 方法总结

这里是独立的教学总结。
```

- 独立题目使用顶格 `##### 例1`、`变式1`、`练习1`、`检测1`、`题1` 或 `第1题`；下一个 H1–H5 结束当前题目。题内小标题使用 H6。
- 小问和对应答案可以交替排列。短题完整同页，长题新页起排后按段落／列表／留白续页；学生留白不压缩、不删除，允许合理的空白尾页。
- 顶格独立一行 `------`（恰好 6 个半角连字符）强制后文从新页开始，支持题内换页；其他长度的横线保持普通 Markdown 语义。代码、引用等字面内容不触发。
- 普通讲义不必写 YAML。题库组卷使用 `question_type`、`knowledge_nodes` 等正式字段；未知来源和结构关系保持未知，详见规范的元信息约定。
- 选择、填空、判断题用 `!{}`／`?{}` 标注答案，只写 `[!solution]- 解析`；计算、解答、证明等题的 `[!answer]-` 写标准解题步骤和结论，独立构成满分答案，`solution` 按需写补充说明。

| 写法 | 学生版 | 教师版 |
| --- | --- | --- |
| `?{42}`、`?{$\frac{1}{2}$}` | 隐藏答案，按测量宽度留横线 | 显示答案，保留横线 |
| `!{B}`、`（!{ACD}）` | 隐藏答案，无横线 | 显示选项 |
| `==重点==` | 普通高亮 | 普通高亮 |
| `[!answer]-`／`[!answer]+` | 隐藏标准解题步骤与结论，按实测高度留白 | 显示完整满分答案 |
| `[!solution]-`／`[!solution]+` | 默认隐藏解析或补充说明且不留白，可开启留白 | 默认显示，可关闭 |
| 其他 `[!type]+/-` | 隐藏并留白；嵌套教师块不重复计数 | 显示 |
| 无 `+/-` 的 Callout | 共享内容，直接显示 | 默认显示；`solution` 可关闭 |

无标记的 `[!answer]` 会在学生版显示。原生 Obsidian 中 `+/-` 仍保留折叠语义；导出只在临时副本中展开和转换。

已发布 0.1.10 使用旧答案语法 `(==B==)`／`==42==`。迁移到当前版本时须逐项区分答案和强调，不要批量替换所有高亮；插件不会自动改写原文。详见[答案语法与迁移](docs/ANSWER_SYNTAX.md)。

## 安装

本次发布可从 [0.2.4 Release](https://github.com/sunsimilarsun/Mathsemble/releases/tag/0.2.4) 下载三个独立文件：`main.js`、`manifest.json`、`styles.css`。

1. 将三个同版本文件放入 `<vault>/.obsidian/plugins/mathsemble/`。
2. 重启 Obsidian，在社区插件设置中启用 Mathsemble。
3. 安装后核对当前模板与学生／教师双版本输出；自动化与真实宿主验收的范围见[测试记录](docs/TESTING_0.2.4.md)。

插件 ID 为 `mathsemble`，要求桌面版 Obsidian 1.5.0 及以上。社区目录审核／上架状态以实际审核结果为准。

## 导出诊断与支持边界

- 图片失败、局部数学渲染错误会显示警告；确认“允许不完整的 PDF”后可继续。相同问题复检保留确认，新增问题要求重新确认；不完整输出不能当作内容完整。
- 题目丢失、留白高度异常、版心越界或无法安全分页会阻断导出。
- `$x=?{2}$` 仅隐藏公式中的数值，`?{$x=2$}` 隐藏整个等式。公式内部槽保留 A4 导出支持，原生 Reading View／Live Preview 的全面适配尚未验收。
- Reading View 对混合转义答案标记的区块仍采用保守跳过策略。复杂 HTML、懒续行、第三方 Markdown 扩展、TikZ、跨主题样式需要真实宿主检查。
- “查看诊断”中的可定位问题提供“定位预览”和“定位原文”。临时 A4 指向原题卡或知识笔记，可靠匹配时定位到行，否则打开对应文件；普通文档定位本次读取的文件。原文或未保存编辑已变化时，需保存修改后重新读取；临时预览需返回编排核对来源并重新预览，避免使用旧行号。
- 手动搜索、题篮、知识混编及条件抽题已加入；题型配额和题族驱动组卷仍待后续开发，见[功能矩阵](docs/FEATURE_MATRIX.md)与[路线图](docs/ROADMAP.md)。

## 开发与验证

```sh
npm ci
npm run check
npm run prepublish-check
```

`src/plugin.js` 保留既有渲染源码；新组题模块维护在 `src/assembly-*.cjs`，构建将其同步到标记区，再生成 `main.js`。不要手改生成标记区。`styles/assembly.css` 维护组题界面样式。`styles.css` 是打印 CSS 唯一编辑来源；构建同步其打印部分到源码中的生成字面量，再生成 `main.js`。构建统一使用 LF，CRLF 检出不应导致语义校验误报。修改后同时保留源码和构建产物。

浏览器回归需要 Chrome／Chromium。Linux 测试会查找常用安装路径；Windows PowerShell 可显式设置：

```powershell
$env:CHROME_PATH = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
npm run prepublish-check
```

CI 配置覆盖 Linux 和 Windows；CI 缺少浏览器时应失败。本地未指定可用浏览器会跳过对应测试，不能据此声称完成布局验收。模板回归会检查题目边界、答案投影和元信息；数学正确性另需审校。自动化验证不能代替真实 Obsidian 和完整 PDF 验收。

模板回归默认读取仓库内 [版本化测试样例](tests/fixtures/templates/v1/README.md)，不依赖个人内容库。需只读核验生产模板时，可将 `MATHSEMBLE_TEMPLATE_DIR` 设为内容库中 `数学教学/模板&规范/` 的实际路径，再运行 `node --test tests/templates.test.cjs`。

真实公式回归默认使用 `npm ci` 安装的固定版本 MathJax 4 与 TeX 字体，由本地临时服务器提供资源，并禁止测试页面访问外部 CDN。宿主对照可额外设置 `MATHSEMBLE_MATHJAX4_DIR`，指向本机 Obsidian 的完整 `lib/mathjax` 资源目录；常规测试和 CI 不需要本机 Obsidian。

## Network access and files outside the vault

Mathsemble is a desktop-only, local-first Obsidian plugin with no built-in telemetry or account service. Exporting notes that reference remote HTTP(S) images or fonts can make network requests. Explicit `file://` references can read resources **outside the vault**. The PDF exporter writes temporary HTML in the operating system's temporary directory and attempts cleanup. Exports are saved locally in `ExamExports/`; the plugin does not automatically share them. See [Privacy details](docs/PRIVACY.md).
