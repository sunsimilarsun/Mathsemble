# 题族筛选与换题

题族来自题卡已有的 `family_id`，不要求迁移旧题卡，也不增加方案字段。读取 v1／v2／v3，显式保存仍写 v3。配额约束使用独立的[组卷记录](BLUEPRINTS.md)。

## 查找同族题

在选材页选择“题族”，或点击题卡的“查看题族”。后者会清除其他筛选（包含 P2 的使用条件），收起正文预览、展开并定位到题族标题，显示包含原题在内的所有已收录成员；可以继续追加题型、难度等条件。题族标题下提供“返回全部题目”，只有一个成员时明确提示暂无其他同族题。重复点击同一题族也会重新定位，不修改编排或题卡。

题族选项显示成员数，选中后显示全族的教学层次和角色分布；列表数量仍按当前筛选计算。查看题族是选材中的列表导航，不是同族换题弹窗。导航修复的验证范围见[测试记录](TESTING_FAMILY_NAVIGATION.md)。

“题族状态”可区分已归族、未归族和字段异常。字符串 ID 只去掉首尾空白，大小写和不同 Unicode 拼写保持区别；字面 ID `all` 也视为普通题族。缺失、null、空字符串或全空白表示未归族。列表、数字等非法值保留异常诊断，不能据此换题。

`parent_id` 是可选的显式母题 ID，与同族分组分开。索引会提示找不到母题、重复 ID、指向自身、指向知识笔记、循环及跨族引用。没有母题字段的变式仍是合法旧题；同族或角色相近不会自动生成母子关系。所有诊断只读原卡。

## 替换编排中的题

1. 在“预览编排”中打开目标题的“更多 → 同族换题”。
2. 确认采用的配额记录。尚未保存的本次记录优先使用；唯一匹配的已存记录自动采用；多份记录匹配时必须明确选择。
3. 默认沿用当前素材筛选。可以主动取消这一选项；已知配额行的条件仍然必须满足。已锁定的目标需明确勾选“解除此题配额锁定后换题”，再刷新候选。
4. 查看当前题与替代题的题型、难度、层次、方法和知识标签，阅读候选正文，点击“选用此题”。同族只代表所登记的题族关系，不保证数学等价或难度相同。
5. 核对编排后保存方案。如果沿用了配额记录，保存时同时写出新的记录，旧记录保留。

替换仅修改该编排项的 `sourceId`、`sourcePath`、`sourceFingerprint`；`entryId`、位置、卷内标题、卷内角色及其他设置保持。已入卷的其他题、目标自身、身份冲突项及其他题族不会成为候选。候选为空时原编排保持，不放宽条件。

选用前关闭窗口或取消待执行的操作，不会改写方案、源卡或历史记录；关闭窗口不会撤销已经应用的换题。应用前重新扫描并校验源文 SHA-256、方案、目录设置与约束；在等待期间变化会拒绝应用旧候选。换题不自动接受已经变化的旧题来源，应先在编排工作区核对。

## 与配额配合

匹配记录依据严格方案摘要及逐项来源归属，不根据文件名猜测。已匹配记录须完整通过当前来源和配额核验，失效时直接报错，不退回无约束换题。题族上限覆盖整个方案，包括未计入配额行的原有题。显式解锁只移除目标槽位的锁，其他锁、原配额行与题族上限保持。

未找到有效匹配记录时，窗口会说明历史配额未知，只按当前题族、所选素材筛选及防重复规则处理。手工改过方案或丢失记录时，不能凭旧文件名称恢复过去的约束。

蓝图候选尚未应用时也可点击“同族换一道”；锁定题须先解锁，其他槽位保持，候选不满足约束时保留原组合。蓝图中的“每个题族最多题数”留空表示不限；未归族题各自独立，不共享一个空题族名额。

本次功能不生成新题、不推断相似题、不改写知识标签或母子关系，也不记录课堂使用次数。
