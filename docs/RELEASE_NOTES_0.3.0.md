# Mathsemble 0.3.0

本版增加媒体冻结与教师材料归档、按配额组卷、题族筛选与受约束换题，并修复阅读视图中转义示例影响真实答案槽显示的问题。发布提交、最终资产摘要和发布状态见 [0.3.0 验证与发布记录](TESTING_0.3.0.md)。

## 导出记录与教师材料归档

- A4 预览在图片进入测量前捕获资源字节，同一预览和同次学生／教师双版导出共用这些字节。导出前用 SHA-256 复核已识别的库内本地媒体；同路径、同大小的内容变化也会阻止旧预览继续导出。
- 每次导出保存独立记录，分别报告输出文件、记录和归档的状态。已经保存的第一份文件，不会因第二份失败或取消被改记为未保存；写入结果不确定时明确标为待核实。
- 在 A4“更多”中可选“同时归档本次教师材料（原题、图片、方案与输出）”。归档包含捕获的原文、可识别媒体、适用时的编排方案和来源映射，以及生成产物；默认不勾选，不覆盖历史包。

**教师材料归档可能包含答案、解析及学生页面隐藏的图片。** 即使只导出学生版，归档也保存完整原文，应留在教师侧。给学生分发核对后的 PDF／HTML，不分发整个归档或导出记录。归档目前不是可直接回导的题库包；`complete` 只表示本次捕获范围内材料完整，未支持的嵌入、SVG 外链等会保留缺口说明。详见 [媒体冻结与导出归档](EXPORT_ARCHIVE.md)。

## 按配额组卷

- 新增“按配额组卷”，可命名保存蓝图，按题型、难度、教学层次、知识点等设置多行条件与题数。分配同时考虑全部行，一题只计入一行，全部满足才应用；不足时不自动放宽条件或先加入部分结果。
- 支持锁定、重抽未锁定题、只替换一个槽位，以及明确把编排中的已有题计入某行。保留已有题的位置、编排项 ID、卷内标题和角色。
- 可设置整个方案每个题族的题数上限。未归族题各自独立，不共享一个空题族名额。
- 蓝图和执行记录分别保存在独立目录，不向 v3 方案增加字段。方案保存成功后再写配额记录；记录失败会单独提示，保留当前工作区可重试。

详见 [按配额组卷](BLUEPRINTS.md)。

## 题族筛选与换题

- 按现有 `family_id` 查找同族题，显示成员数及层次／角色分布；区分未归族与字段异常。显式 `parent_id` 提供缺失、冲突、循环等诊断，不推断母子关系，也不回写原卡。
- 编排“更多 → 同族换题”仅更新目标的来源 ID、路径和指纹，保留位置、卷内标题、角色与其他设置。同族关系不表示数学等价或难度相同。
- 待保存的配额记录优先使用；唯一匹配记录自动采用，多份匹配须明确选择。已知记录的行条件、真实锁定和全卷题族上限继续有效；失效时拒绝换题，不退回无约束流程。
- 锁定题必须显式解除目标槽的锁后再换。成功后生成新记录，其余锁与旧记录保持。应用前重新核对来源与当前方案，异步期间变化不会覆盖较新的编排。

详见 [题族筛选与换题](FAMILIES.md)。

## 阅读修复与兼容

修复阅读视图遇到转义答案槽示例后跳过真实答案槽的问题，继续保护代码、链接和字面内容，保留多视图隔离与换文件重置行为。

题卡不新增必填字段，无需批量迁移；方案继续读取 v1／v2／v3，打开旧文件只在内存中归一，显式保存写 v3。没有配额记录、记录损坏或版本过高，不影响旧方案独立打开。正式 0.2.5 可读取保留原结构的 v3；正式 0.2.4 原有“不读取 v3”的限制不变。

沿用 0.2.5 的答案与 Callout 规则：只有 `-` 块按学生／教师版本过滤，`+` 和无标记块共享；从 0.2.4 或更早版本升级时仍须按 [Markdown 规范](MARKDOWN_SPEC.md) 核对答案隐藏标记。本版不会批量修改源笔记。

## 安装与验证边界

桌面版 Obsidian 最低版本仍为 1.5.0，插件 ID 为 `mathsemble`。更新前备份当前插件三件套、配置与方案，将本次发布的 `main.js`、`manifest.json`、`styles.css` 一起替换到现有插件目录，避免混用版本。已有导出记录和材料归档是持久资料，不属于应随更新删除的缓存。

发布准备前的 Windows 完整检查为 **811 项通过、0 失败、0 跳过**。真实 Windows Obsidian 分阶段验证了阅读内容、原生 PDF、媒体归档、配额和题族流程；已检查的 10 份 PDF、42 页来自不同阶段构建，**不是最终 0.3.0 发布字节的一次完整重导**。

版本变更后的本地检查、目标提交 CI、发布资产和教学插件更新状态由 [验证记录](TESTING_0.3.0.md) 分别登记，不预填成功。原生验收未覆盖 macOS、实体打印、所有第三方主题／渲染器、真实远程服务故障及宿主崩溃恢复，也不代表已审校整个教学库或完成真实课堂验收。
