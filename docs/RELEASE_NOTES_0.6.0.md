# Mathsemble 0.6.0

## 重启后继续选题

第一次打开“选材与编排”时会读取题库并显示进度。完成后，插件把浏览用的正文和元信息保存在这台设备的 Obsidian 配置中。再次打开时会核对当前库的文件清单，重新读取新增或发生变化的内容。原有章节、小节、知识点筛选和正文搜索均可使用。

同步期间若个别题卡暂时无法读取，仍可从其余题目中选材。页面列出失败文件，可在同步完成后重试。生成讲义和 A4 预览沿用原文核对流程。

## 升级和清除索引

升级前备份原插件目录和组题方案，将本页的 `main.js`、`manifest.json` 和 `styles.css` 装入现有插件目录，重新加载。现有 v1 至 v4 方案均可打开。

本机索引包含题卡正文及教师答案，按库分开保存。运行“清除本机选材索引”可移除当前库的缓存，下一次刷新将重新读取全库。如果外部工具保留了文件的原时间和大小，刷新时仍显示旧正文，也可用这个命令重建索引。需要回退到 0.5.0 时，可先清除本机索引，再恢复备份中的三个插件文件并重新加载。
