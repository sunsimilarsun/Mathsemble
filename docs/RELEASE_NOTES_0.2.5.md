# Mathsemble 0.2.5 本地合流说明

日期：2026-11-17。状态：本地源码合流，尚未创建远端标签或 Release。公开基线为正式 0.2.4（`bf1d6138b09f507d9deb28893fe5e7474c135763`）。

本轮将本机安装目录中尚未进入正式源码的改动恢复到可维护源码及构建链，保留选材、条件抽题、知识混编、预览编排、临时 A4、双版输出及来源检查。版本号区分正式 0.2.4 与这批额外改动；不再仅凭旧安装 manifest 的 0.2.4 判断字节和行为一致。

## Callout 与答案显示

- 只有 `-` Callout 按学生／教师版本过滤；`+` 和无标记块都是共享内容。
- 未被祖先整块隐藏的 `answer-` 固定在学生版生成实测留白，在教师版显示。其他 `-` 类型分别选择学生留白与教师显示，默认两项均关闭。
- 外层隐藏包含全部后代，内层 `answer-` 不单独恢复。选中的外层留白测量完整原块，不受教师显示选择影响，也不重复累计后代。
- 阅读视图新增“显示／隐藏答案”按钮及命令，作用于当前视图；切换文件重置，不修改原文或 A4 设置。

正式 0.2.4 使用不同的 `+/-` 契约。升级后逐项检查原来用 `+` 隐藏的答案，以及需要在教师版显示的 `solution-` 等类型；插件不会批量改写源笔记。现行语法见 [Markdown 规范](MARKDOWN_SPEC.md)。

## 方案与试听兼容

- 方案读取 v1／v2／v3，显式保存写 v3。旧 `solutionSpaces`／`showSolution` 按原值映射到 `solution` 类型选择，读取本身不写文件。
- 正式 0.2.4 无法读取 v3。回退前保留升级前方案副本，不能通过只改 JSON 版本号丢弃新设置。
- 普通文档试听课题按 `title` → `课题名称` → `titile` 读取；生成的 `note_type: handout` 按 `titile` → `title` → `课题名称`。按字段是否存在决定优先级，显式空值不回退，保留独立课程标题。
- 接回试听课程表及页脚样式调整。教师缺省仍为“孙老师”，其他缺失信息不编造。

资源处理已有单项超时、总截止时间、取消及单次任务缓存；本轮纠正文档中仍写作“待实现”的条目，不把既有能力计为新增功能。
