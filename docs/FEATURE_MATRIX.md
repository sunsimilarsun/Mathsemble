# 当前功能与验收边界

对应源码：0.2.4 开发版，正式基线为 0.2.3。代码存在、自动测试通过和真实 Obsidian 验收是不同状态；历史版本记录见 [变更索引](CHANGELOG.md)。

| 子系统 | 当前实现 | 验证与剩余边界 |
| --- | --- | --- |
| 长讲义 | 原文、学生、教师三种投影；H5 整题边界 | 0.2.3 长讲义／三外观双版 PDF 及用户验收见外观记录；0.2.4 增量单列 |
| 答案槽 | `?{}` 填空、`!{}` 选择，原生高亮保留 | 解析与组件回归；公式内部槽的原生阅读适配未全面验收 |
| Callout | `+/-` 教师专用；answer 留白；solution 独立选项 | 嵌套投影及测量回归；复杂懒续行和第三方扩展需宿主检查 |
| A4 分页 | 短题整题同页，长题新页起排，留白总高与溢出检查 | Chromium 布局回归；系统字体与打印驱动差异需验收 |
| 局部渲染警告与定位 | 已知警告确认后可导出，新问题重新确认；支持定位预览及可靠来源行，原文变化后拒绝旧定位 | 诊断信息与打印内容隔离；精确来源不可确定时标明题目／文件范围 |
| 题卡组卷 | 当前文件夹按题型或主知识点分组 | 正式元信息字段与模板回归；不递归组卷 |
| 模板 | 单选／多选／填空／判断／解答五类题卡，通用讲义、最小讲义示例、考前复习示例、混合试卷 | 自动核对边界、答案投影、字段和链接；数学另行审校 |
| 阅读样式 | 九类教学 Callout、答案槽交互 | Chromium 样式回归；多主题、用户 CSS 需宿主验收 |
| 构建 | CSS 单一来源、源码生成 main.js、LF 输出 | 干净构建与 CRLF 回归；CI 配置覆盖 Linux／Windows |
| 资源处理 | 远程及本地引用内联、临时打印 HTML | 隐私披露与窗口生命周期回归；请求取消／缓存仍待改进 |
| 搜索与编排 | 跨目录筛选、题篮、整篇知识混编、手工排序、保存方案、生成 Markdown | 条件抽题先生成候选再显式加入；知识小节截取及题型配额未实现 |
| 条件抽题 | 按现有筛选及数量随机选择题目，候选可预览／移除／重抽，显式加入编排 | 排除已用题和身份冲突，覆盖全部结果，加入前读取来源并原子核验；不自动放宽条件 |
| 扁平知识属性 | 知识多层级筛选、同学科共同纯文本标签关联、多知识页预览入口 | 模块与隔离Chromium回归通过；18篇现有知识的生成已核对，宿主待验 |

正式交付需记录目标提交及 [Obsidian 宿主验收](OBSIDIAN_HOST_ACCEPTANCE.md)结果，不把模拟宿主或局部测试当作完整产品验收。
