# 当前功能与验收边界

0.4.0 在 0.3.1 的标题识别与打印修复之上，整合 P2、相似题和引用式讲义。下表保留各阶段的验证范围。版本变化见 [0.4.0 发布说明](RELEASE_NOTES_0.4.0.md)，主流程与保存范围见[产品设计](PRODUCT_DESIGN.md)。

0.3.0 的本地完整检查为 811 项通过、0 失败、0 跳过；该阶段 Windows 隔离 Vault 的操作、截图与原生 PDF 范围见 [0.3.0 测试记录](TESTING_0.3.0.md)和 [P0／P1 实施验收](research/question-banks-2026-11-17/IMPLEMENTATION_ACCEPTANCE.md)。各阶段按精确 bundle 摘要区分，这些结果不证明 P2、macOS、实体打印或所有第三方插件通过。

## 已发布的 0.3.0 基础能力

| 子系统 | 当前实现 | 验证与剩余边界 |
| --- | --- | --- |
| 长讲义 | 原文、学生、教师三种投影；顶层 H5 独立内容块边界 | 0.3.0 阶段三外观双版长讲义 36 页完成原生输出及渲染复核；样例范围见实施验收 |
| 答案槽 | `?{}` 填空、`!{}` 选择，原生高亮保留 | 解析与组件回归；公式内部槽的原生阅读适配未全面验收 |
| Callout | 仅 `-` 按版本过滤；`answer-` 固定学生留白／教师显示；其他 `-` 按类型分别选择，默认不留白／不显示；`+` 和无标记共享 | 祖先隐藏时整棵子树隐藏，内层 answer 不单独恢复；学生测量保留已选原块全部后代，复杂懒续行与扩展仍需宿主检查 |
| A4 分页 | 短题整题同页，长题新页起排，留白总高与溢出检查 | Chromium 布局回归；系统字体与打印驱动差异需验收 |
| 局部渲染警告与定位 | 已知警告确认后可导出，新问题重新确认；支持定位预览及可靠来源行，原文变化后拒绝旧定位 | 诊断信息与打印内容隔离；精确来源不可确定时标明题目／文件范围 |
| 题卡组卷 | 当前文件夹按题型或主知识点分组 | 正式元信息字段与模板回归；不递归组卷 |
| 模板 | 生产模板独立维护于内容库；仓库使用版本化最小样例回归，外部模板审计显式启用 | 不以测试夹具目录代替当前生产模板清单；数学与实际生产模板另行核对 |
| 阅读样式与答案开关 | 九类教学 Callout、答案槽交互；阅读视图按钮／命令显示或隐藏答案，文件切换重置 | 0.3.0 阶段原生内容显隐、多视图隔离、默认及 Minimal 主题检查通过；公式内部槽仍有既有边界，不泛化到所有主题和虚拟滚动情形 |
| 构建 | CSS 单一来源、源码生成 main.js、LF 输出 | 干净构建与 CRLF 回归；CI 配置覆盖 Linux／Windows |
| 资源处理 | 远程及本地引用内联、临时打印 HTML；单项超时、总截止时间、取消及有界单次任务缓存已实现 | 取消不撤回已保存文件，关闭／切换预览使过期任务失效；仍需覆盖真实网络、宿主与文件系统故障 |
| 搜索与编排 | 跨目录筛选、题篮、整篇知识混编、手工排序、保存方案、生成 Markdown；单列自动预览、筛选标签、完整预览与窄分栏切换，已选数量入口进入预览编排 | 条件抽题先生成候选再显式加入；0.3.0 使用整篇材料，稳定片段属于下表 P2 增量 |
| 配额组卷 | 多行蓝图、锁定与重抽、逐题替换、已有题显式归属、全卷题族上限、独立运行记录 | 全局分配与完整应用；纯引擎、服务、真实 Chromium 和原生保存重开验证通过 |
| 题族操作 | 精确题族筛选、角色层次分布、显式母题诊断、同族换题 | 空族不合并；已知配额/锁不降级；原生验证位置、标题、角色与旧记录保持 |
| 媒体与归档 | 测量前冻结图片、同会话双版共享、本地 SHA-256 变化拦截、独立导出记录、可选教师材料归档 | 真实双版 PDF/HTML 与本地图片变化验证；原归档不是一键可回导包，P2 材料包另有显式格式；未知依赖不宣称完整 |
| 预览编排 | 已选题目／知识／分区连续预览；紧凑工具行、拖动和上下移动、标题角色直接编辑，更多菜单提供指定位置、原文和移除 | 共用方案与来源核验；Windows 原生保存／重开与换题保持设置通过；题干编辑通过原笔记 |
| 分区整体移动 | 标题及其下方题目／知识作为整体；箭头交换相邻分区，拖动按目标分区排序，更多菜单按分区序号定位 | 保留首分区前言与区内顺序，空分区可移；普通内容仍单项移动，移除分区标题保留正文；验证记录见 [0.2.4 测试记录](TESTING_0.2.4.md) |
| 流程与保存提示 | 统一选材／预览编排／排版与导出入口；区分方案保存与最近读取的来源状态；临时预览、保存方案与保存讲义副本分别操作 | 预览不自动保存方案或生成 Markdown；单独打开保存后的讲义使用普通文件流程 |
| 临时 A4 预览 | 从当前编排与来源快照直接排版；来源变化后返回编排核对；诊断映射回原题卡或知识笔记 | 原生变源失效／恢复与 v3 来源归档通过；目录内 Markdown 变化保守失效，无法可靠定位时打开对应文件 |
| 课程与默认排版 | 方案保存课程信息、默认外观／版本、留白和各类 Callout 选项；生成讲义写入 `titile/author`；A4 可显式应用回原编排草稿 | 读取 v1／v2／v3，显式保存为 v3；正式 0.2.4 不读 v3，不持久化警告许可，来源变化仍须核对 |
| 试听属性与版式 | 普通文档课题按 `title` → `课题名称` → `titile`，生成的 `note_type: handout` 按 `titile` → `title` → `课题名称`；调整信息表及页脚样式 | 按属性存在性选择，显式空值不回退；教师缺省“孙老师”，其他缺失信息不编造；0.3.0 阶段试听双版 PDF 已复核 |
| 条件抽题 | 按现有筛选及数量随机选择题目，候选可预览／移除／重抽，显式加入编排 | 排除已用题和身份冲突，覆盖全部结果，加入前读取来源并原子核验；不自动放宽条件 |
| 扁平知识属性 | 知识多层级筛选、同学科共同纯文本标签关联、多知识页预览入口 | 模块与隔离Chromium回归通过；18篇现有知识的生成已核对，宿主待验 |

## 0.4.0 整合的 P2 功能

| 子系统 | 功能 | 兼容与验收边界 |
| --- | --- | --- |
| 实际使用账本 | 按班级／课程明确登记已讲授或已布置；保留当时原文、强摘要、来源和编排身份；幂等动作、追加撤销更正、历史查看 | 导出、保存与投影不计使用；无 ID 不跨改名合并。部分使用保留片段与分值，整题筛选保守计为已用。模块与 Chromium 界面已有针对测试；完整及原生结果由 P2 实施记录单列 |
| 使用筛选 | 本班／课程近期未用、最近已讲而尚未布置、上次使用时间；叠加普通选材和条件抽题 | 班级与课程共同隔离；撤销后重新统计；不推断学生掌握度。配额蓝图仍使用自己的条件 |
| 集中题库诊断 | 身份冲突、字段缺项、资源缺失、疑似相同正文及未正常收录材料提示 | 只读诊断；疑似重复不自动合并、不自动改号，数学正确性另需审核 |
| 待入库批次 | Markdown 与明确 JSON profile；持久原件、候选、ID／资源映射及未知字段损耗报告；人工确认后仅创建新文件 | 同路径／同 ID 冲突拒绝；未知 profile 不执行。撤销须有本批创建归属且内容未改，用户后改或替换文件保留；原件与日志不删除 |
| 卷内分值与稳定片段 | 整题分值、显式稳定小问／知识小节选择、完整的小问分值合计 | 不增加旧卡必填字段、不按标题或行号猜锚点；缺失片段或不完整依赖阻断。数据与源文契约见[稳定片段说明](ASSEMBLY_FRAGMENTS.md) |
| 方案按需 v4 | 保留 v1／v2／v3 读取；无新字段仍写 v3；分值或片段引用启用 v4 | 原 v1–v3 文件必须另存，0.3.0 不读 v4；清除全部新增字段后可另存兼容 v3，不能只改版本号 |
| 可校验材料包 | 封装源文、已捕获本地资源及方案；校验后暂存回导，分别保存原字节与重映射候选，可另携带历史旁车／归档 | 未捕获依赖如实 `partial`，阻断问题不提交。历史内部路径不冒充当前可执行记录；不是 QTI，也不宣称支持未知格式、全部 SVG 依赖或所有外链 |
| 逐题投影 | 当前编排的大字号逐项展示、键盘翻页、只揭示当前项、换页重置 | 原方案或来源变化后重新生成；不写题卡、不自动登记教学事实。课堂观感和真实宿主表现须独立验收 |

使用账本、入库原件与映射、提交／撤销日志、配额运行记录、归档均为持久资产，须随题库备份。它们可能含教师原文、答案及隐藏资源，不能当作学生输出分发，详见[隐私说明](PRIVACY.md)。

P2 阶段的完整构建和 Windows Obsidian 实测见 [P2 实施记录](P2_IMPLEMENTATION.md)。0.4.0 的验证范围见[发布说明](RELEASE_NOTES_0.4.0.md)。
