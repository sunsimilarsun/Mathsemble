# 0.1.15 开发版维护：代码、规范与模板

本轮针对本地审查发现的问题实施修复，保持版本号与插件 ID，不创建 Release。

## 行为修复

- 答案索引、预检、转换和 Callout 识别共享行级上下文，保护注释、HTML 属性、原样代码和资源引用；普通段落及基础列表续段中的答案仍会转换。
- 数学答案组件比较包含选择／填空类型，避免类型切换时复用旧横线样式。
- 组卷复检按阶段、文件和问题文本去重；同一警告保留确认，其他文件或公式位置的新警告重新确认。结构与数学渲染阻断保持有效。
- 离线 YAML 读取区分未加引号的空值与文字 `"null"`，宿主元数据继续优先，未知教学角色不误报为非法角色。
- `.gitattributes` 固定文本 LF；构建规范化源码和打印 CSS 换行，测试和许可证检查兼容 CRLF。CI 配置覆盖 Linux／Windows。

## 规范与模板

- [Markdown 规范](MARKDOWN_SPEC.md) 是现行书写入口，补充元信息映射和字面区域边界；旧候选规范只保留替代说明。
- README 保留当前使用、开发、安装、隐私和支持边界；历史版本通过 [变更索引](CHANGELOG.md) 导航。
- 通用和考前讲义改用合法 H5 题目标题，旧答案高亮逐项迁移；五级模板 6 题、通用模板 10 题、考前模板 8 题。
- 三份题卡统一正式字段，保留原 ID、知识点和来源记录。未知章节／教学角色保持空值，来源与层级需按实际题库复核。
- 填空题改为正确答案 1、0；解答题原第二问条件不足，改为采样点水平切线问题，答案为 a=4、y=-5；选择题补全 ACD 的推导。

## 验证方法

新增解析上下文、组卷确认、YAML 空值和实际模板测试；构建测试增加 LF／CRLF 输出一致性和许可证反例。运行带 `CHROME_PATH` 的 `npm run prepublish-check`，再核对生成产物和差异。

Chromium 使用真实浏览器排版及受控 Obsidian API；这不等于完整宿主验收。模板自动测试检查结构与答案投影，数学内容仍需人工复核。通用模板是待填写结构，未知来源／身份不能因测试通过而当作已确认事实。

本地 Windows 验证（2026-10-26）：设置 `CHROME_PATH` 后执行 `npm run prepublish-check`，**201 项通过、0 失败、0 跳过**；新增 39 项覆盖本轮修复及实际模板。源码与 `main.js` 字节一致，SHA-256 均为 `5dcfc01392ae38b5aa2f09b3e66b04a5d5a0df43f541a2f004c4d86c90a56fbd`。变更文档及模板中的 50 个本地链接均有效。Windows CI 已加入配置，本次未推送或运行远程工作流。
