# Mathsemble 0.2.4 开发版

在正式 0.2.3 基础上新增错误一键定位与条件抽题，并优化组题工作区。当前为开发验收版本，尚未创建正式 Release。

## 组题工作区

- 选题页采用“内容筛选、选题与预览”两栏，窄分栏可切换筛选与选题。已选数量入口进入独立的预览编排页，正文占用原右侧编排栏释放的空间。
- 常用筛选直接显示，其他条件可展开；当前条件保留标签，支持逐项或全部清除。
- 结果与候选每行一道题，直接展示正文预览，公式和图片进入可见区域后自动渲染；压缩工具与元信息占用，正文使用整行宽度。
- 预览随内容增长，最长显示 320px；短题不强占固定高度，长题点击“查看全文”，返回时恢复列表位置。候选题和筛选结果可分别展开，已加入的题目有明确标记。
- 每项编排只常驻紧凑工具行：拖动手柄、题号、可编辑标题和角色、上下箭头与“更多”；指定位置、打开原文和移除收纳到更多中。
- 顶部合并讲义标题、模式切换、保存和 A4 预览，新建、打开、另存及 Markdown 输出收纳到“方案操作”；已选数量入口区分题目、知识和分区。添加分区时再展开标题输入。

界面使用 Obsidian 主题颜色，并补充键盘焦点、长标题换行和空列表引导。题目来源、方案数据和打印排版规则保持兼容。

## 预览编排

新增独立的“预览编排”工作模式，按方案顺序连续展示已选题目、知识正文与分区，每行一项。正文末尾按需提供全文展开；短内容已完整显示时不出现展开按钮，长内容或隐藏答案／解析可就地展开。

支持拖动手柄、上移／下移、移到指定编排位置，编辑本次标题和教学角色，以及新增分区、移除内容、打开原文。编排位置包含知识和分区，与题号分开显示。保存与 A4 预览继续使用同一份方案。

切回选题保留筛选和候选；实际修改编排后旧候选失效。来源更新、缺失与冲突仍需显式核对。自动预览沿用渲染取消和并发限制，切换模式或关闭后释放旧任务。

## 错误一键定位

在预览的“查看诊断”中，针对可定位的公式、图片、块边界及分页问题，使用“定位预览”查看对应位置，或使用“定位原文”打开源文件。能可靠匹配时定位到具体行，否则明确退回所属题目或文件。

源文件或未保存的编辑内容已变化时，旧行号不可继续使用，应读取最新内容后再定位。诊断不改写原文，定位信息不进入导出的 PDF／HTML。

单版和双版导出失败也提供来源入口；无法确认具体位置时打开对应原文件。

## 条件抽题

在“知识与组题”工作区的题目页设置知识点、题型、教学层次等筛选条件和数量，生成随机候选题。可以预览、移除或重新抽取；确认后点击“加入编排”，再人工排序、改本次角色或保存方案。

抽取范围为全部符合条件的题目，排除当前编排已用来源及身份冲突。候选不足时显示实际数量，不放宽条件。筛选、扫描、编排或数量变化后需重新生成；加入前重新核对真实来源，失败不会留下部分编排，也不会修改题卡。

## 代码核验修复

- 图片链接仅在 Markdown URL 边界解码一次，Wiki 路径保持字面值，避免百分号文件名与空格文件名相互替换。
- 抽题核验期间监听来源变化；修改、删除、改名或新增冲突来源会拒绝整批加入，保留原编排和原索引，操作结束时清理监听。
- 图片定位使用完整来源目标；说明文字、文件名子串及无法可靠还原的目标退回块或文件定位。
- 整卷高度测量失败后，即使临时测量节点已清理，仍提供可用的来源文件入口。
- 首次并发导出可共用已被另一窗口创建的正确目录；同名文件占用、权限及其他错误仍会阻止输出。

## 使用与验收

安装时将同一候选包中的 `main.js`、`manifest.json`、`styles.css` 一起覆盖现有 Mathsemble 插件目录，再重新启用插件。现有外观、课程属性、长公式换行和双版 PDF 功能继续沿用 0.2.3 基线。

候选 v7 的本地完整 `prepublish-check` 共 507 项通过，0 失败、0 跳过；包含构建、真实 Chromium 功能检查和源码／产物一致性检查，详情见 [测试记录](TESTING_0.2.4.md)。新功能的视觉与真实 Obsidian 操作验收由用户负责。
