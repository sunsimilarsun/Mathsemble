# Mathsemble 0.2.4

本次发布将选材、预览编排和 A4 输出连成完整流程：每行直接看一道题，调整题序或整区移动，保存课程与排版设置，直接预览并导出学生版／教师版 PDF。需要 Markdown 文件时，再单独保存讲义副本。

## 选材与预览编排

- 主入口为“打开选材与编排”。结果和抽题候选在进入可见区域时自动渲染题干、公式与图片，每行一道题；长内容可查看全文。
- “预览编排”连续展示已选题目、知识和分区。支持拖动、上下移动、指定位置，直接修改本次标题和教学角色；题干修改通过“打开原文”。
- 分区标题及其后直到下一个分区之前的题目和知识一起移动，保留区内顺序。拖到另一分区的标题或内容上时，向下移到目标分区之后，向上移到目标分区之前。
- 分区可按序号指定位置，空分区也可移动；首个分区之前的内容保持原位。普通题目和知识仍按单项移动，“移除分区标题”保留正文。
- 条件抽题覆盖全部筛选结果，排除已用题和身份冲突；候选可预览、移除或重抽，确认后加入编排。数量不足不自动放宽条件，加入前重新核对来源。

## 临时 A4 与保存范围

“预览 A4”使用当前编排和来源快照直接排版，不创建中间 Markdown，也不自动保存方案。三个操作分别负责：

- **保存方案**：保存顺序、来源引用、本次标题和角色、分区、课程信息与默认排版；正文保留在原笔记。
- **保存讲义副本**：在 `Mathsemble/讲义/` 新建当前内容的 Markdown 快照。
- **预览 A4**：检查排版，保存当前版本 PDF、学生／教师双版 PDF 或 HTML。

临时预览期间，所配置题库和知识库目录中的 Markdown 新增、修改、删除或改名会使旧预览失效并阻止导出，包括未选素材的变化。使用“返回编排更新”，刷新素材、核对并按需接受来源更新后重新预览；返回只显示当前草稿，不自动接受或保存。

单独打开已保存的讲义副本时，按普通文档读取、重新读取和定位该副本，不追溯上游素材。完整操作与保存关系见[产品设计](PRODUCT_DESIGN.md)。

## 课程与排版随方案保存

在“方案操作 → 课程与排版”中设置课程信息、默认版本与外观、留白和解析选项，保存后可恢复。A4 的“应用到编排方案”将本次设置带回原工作区草稿，再通过“保存方案”保存；编排已更换、修改、关闭或忙碌时拒绝旧窗口回写。

生成讲义明确写入 `titile`、`author` 等课程属性。课题默认跟随讲义标题，也可单独填写或留空。已有文档的试听表头仍仅读取 `titile`（按此拼写）作为课题，教师读取 `author`，缺失或空白时使用“孙老师”。

旧 v1 方案读取时在内存补默认设置，显式保存后升级为 v2；**旧版插件不能读取新保存的 v2 方案**。警告确认、跳过内容许可等运行状态不随方案保存。

## 错误定位与可靠性

预览的“查看诊断”可定位公式、图片、块边界和分页问题。临时预览指向原题卡或知识笔记，能可靠匹配时定位到行，否则打开对应文件；源文或未保存的编辑已变化时拒绝旧定位。单版和双版导出失败也提供来源入口。

本次还修复图片路径重复解码、图片说明误作定位目标、抽题扫描期间来源变化、整卷测量失败后来源入口丢失，以及首次并发导出目录创建冲突。来源监听、取消和超时结束后释放；标题映射不可靠时停止猜测来源。
