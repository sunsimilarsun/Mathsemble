## 兼容与限制

- 不修改用户 Markdown、YAML、答案内容、普通 `==高亮==` 或已确认的 answer/solution 设置。
- 实际教师专用标记仍是 `[!type]+/-`；Callout 类型自身不改变共享/教师专用权限。
- 支持本轮覆盖的显式引用层级写法；不宣称任意 Markdown 扩展、原生 HTML Callout、复杂跨层列表或省略引用符号的懒续行全部可靠支持。源码与 DOM 树无法匹配时必须失败退出。
- 测量投影移除不需要书写空间的教师专用 solution；学生版仍需显示的共享 solution 不会被忽略。
- 学生留白不压缩、不删减；保持等高总量核验及允许空白尾页。
- 原有导出语法不变，无新的运行时依赖。编辑普通正文仍可缓存复用，滚动/选区变更不重新扫描全文。
- 旧 teacherOnlyCalloutIndices 仅保留作兼容/回归助手；生产三条测量路径统一使用经过结构校验的计划对象。
