## 保留旧内容

- 原题卡仍是内容事实源，不增加必填字段，不批量改正文。没有稳定片段标记的旧题卡继续整题加入。
- 使用账本、入库批次和迁移映射是独立持久资产，备份必须保留；它们不是可重建的索引缓存。
- v1／v2／v3 保持读取。未启用新字段的方案仍可保存为 v3；卷内分值或稳定片段使用 v4，旧方案第一次启用这些功能时另存，保留原文件。0.3.0 不支持 v4。
- 题目 ID 与版本摘要分别保存。正文相同只能形成疑似重复候选，不自动合并；没有 ID 的路径回退不跨改名推定同一身份。
- 使用事实必须由教师显式登记。导出、保存或课堂投影均不自动表示已讲授，不推断学生掌握度。

## 稳定片段的可选语法

小问使用顶层成对注释，`stem` 为所有小问共用题干，`part` 的 ID 在同题中稳定；知识用 `section`。示意如下（占位示例，并非生产内容）：

```markdown
<!-- mathsemble:stem -->
共用条件及共用题图。
<!-- mathsemble:end -->

<!-- mathsemble:part solve-x -->
求 x：?{2}。

> [!answer]- 答案
> 本小问的完整得分步骤。
<!-- mathsemble:end -->
```

片段必须完整容纳该小问的输入、答案、解析和图片引用。不能以当前行号、标题序号或前端展示顺序代替稳定身份。缺失、重名、未闭合和嵌套标记阻断片段使用；源文变化仍先经过来源更新核对。改变片段 ID 视为原引用失效。同族换题需先切回整题，不能自动把另一题的同名小问当作原片段。

## 已实现的操作入口

编排页的“方案操作”集中提供“实际使用账本”“题库诊断与入库”“逐题投影”。每项素材的内容设置可选整题分值、稳定小问或知识小节；完整语法、依赖规则和 v4 结构见 [ASSEMBLY_FRAGMENTS.md](ASSEMBLY_FRAGMENTS.md)。

- 使用账本按班级／课程保存显式登记和撤销事件，支持近期未使用、已讲未布置筛选；选材提交前重新核对账本。导出和投影不会自动登记。记录保存原文快照及分值／片段范围，损坏或并发变化会阻断本次登记。
- 题库管理集中报告元数据、身份、关联、资源和疑似重复；Markdown、明确 JSON profile 与材料包先保存原件和损失报告，再由教师确认入库。入库只创建新文件，撤销仅处理本批创建且未被编辑的文件。
- 方案分值与片段属于编排，不改写源题。已有配额绑定的分值修改会派生新的配额记录，保留锁及归属；配额绑定项不能直接改为片段，同族换题也不能静默继承另一题的片段。
- 材料包保存源文、依赖媒体和方案的原始字节及校验信息，回导显式映射路径／ID。缺失依赖会报告不完整；历史旁车和归档保留为原件，不冒充已经恢复可运行的历史记录。
- 课堂投影以编译来源映射逐项展示，支持键盘翻页、当前项揭示答案和换页恢复学生状态。学生状态在渲染前移除答案，不能从隐藏的教师 DOM 中泄露其他题答案。
