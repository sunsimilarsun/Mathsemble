## 保留旧内容

- 原题卡仍是内容事实源，不增加必填字段，不批量改正文。没有稳定片段标记的旧题卡继续整题加入。
- 使用账本、入库批次和迁移映射是独立持久资产，备份必须保留；它们不是可重建的索引缓存。
- v1／v2／v3 保持读取。未启用新字段的方案仍可保存为 v3；卷内分值或稳定片段使用 v4，旧方案第一次启用这些功能时另存，保留原文件。0.3.0 不支持 v4。
- 题目 ID 与版本摘要分别保存。正文相同只能形成疑似重复候选，不自动合并；没有 ID 的路径回退不跨改名推定同一身份。
- 使用事实必须由教师显式登记。导出、保存或课堂投影均不自动表示已讲授，不推断学生掌握度。

## 稳定片段的可选语法

小问使用顶层成对注释，`stem` 为所有小问共用题干，`part` 的 ID 在同题中稳定；知识用 `section`。示意如下（占位示例，并非生产内容）：

```markdown
<!-- mathsemble:stem -->
共用条件及共用题图。
<!-- mathsemble:end -->

<!-- mathsemble:part solve-x -->
求 x：?{2}。

> [!answer]- 答案
> 本小问的完整得分步骤。
<!-- mathsemble:end -->
```

片段必须完整容纳该小问的输入、答案、解析和图片引用。不能以当前行号、标题序号或前端展示顺序代替稳定身份。缺失、重名、未闭合和嵌套标记阻断片段使用；源文变化仍先经过来源更新核对。改变片段 ID 视为原引用失效。同族换题需先切回整题，不能自动把另一题的同名小问当作原片段。
