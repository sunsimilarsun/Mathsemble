# Mathsemble Markdown 书写规范

规范版本：v1.2（按题型区分标准解答与解析）

对应插件：0.1.15 开发版

更新日期：2026-10-27

本版明确各题型的答案与解析分工，沿用五级题目标题、现有答案槽语法和学生／教师显隐规则。

## 1. 最少书写约定

**每道题以顶格五级标题开始，例如 `##### 例1`；到下一个一至五级标题之前，或者文件末尾，都是同一道题。题内小标题使用六级。**

不需要给讲义内的每道题写 YAML、结束标签或外层 Callout。程序不会在导出时改写源 Markdown。

| 级别 | 用途 | 示例 |
| --- | --- | --- |
| `#` | 讲义名称 | `# 二次函数专题` |
| `##` | 章节／板块 | `## 一、典型例题` |
| `###` | 专题或分节 | `### 最值问题` |
| `####` | 题型或教学环节 | `#### 配方法` |
| `#####` | 独立题目，或独立非题目内容 | `##### 例1`、`##### 方法总结` |
| `######` | 当前题目的内部小标题 | `###### 第（1）问`、`###### 解法二` |

一级到四级不必全部写齐，可以直接从二级板块进入五级题目。

## 2. 合法题目起点

只把顶格的五级 ATX 标题作为题目起点。`#####` 后至少一个空格；题标必须位于标题内容开头。

推荐：

```markdown
##### 例1 二次函数的最值
##### 变式1：限制定义域
##### 练习1
##### 检测1
##### 题1
##### 第1题
```

兼容 `例题1`、`例一`、`变式一`、`练习题1`、`检测题1`、中文或全角数字，以及 `##### 【例1】 标题`。编号后接空格、冒号等分隔，再写名称；不要写成 `##### 例1已知……`。

不同板块重复“例1”允许存在：显示题号不是内部唯一身份。

以下不自动开始新题：

```markdown
### 例1
**例1**
1. 已知……
（1）求……
###### 例2
```

旧式题标和错误级别中的明确题名会显示边界提示，但不再按旧规则自动拼成受保护的题目。普通数字列表可能是题目、步骤或小问，程序不会猜测。

标题必须位于讲义顶层。代码块、引用／Callout、数学块、注释中的题目标记不作为讲义边界。缩进标题、原生 HTML 标题或其他特殊扩展若造成源码与渲染结构不一致，会停止严格分页，而不是静默合并。

## 3. 题目何时结束

| 遇到的内容 | 结束当前题目？ |
| --- | --- |
| 下一道五级题目标题 | 是，同时开始下一题 |
| 五级非题目标题，例如 `##### 方法总结` | 是，之后是普通讲义内容 |
| 一级、二级、三级、四级标题 | 是 |
| 六级标题 | 否 |
| 第（2）小问题干、答案后的普通文字 | 否 |
| `answer`、`solution`、其他题内 Callout | 否 |
| 题图、公式、表格、选项、空行 | 否 |
| 两侧有空行的水平分隔线 `---` | 否 |
| 文件结束 | 是 |

兼容的 Setext 一级／二级标题也会结束题目。普通横线前后请留空行，避免把前一行变成 Setext 标题。

**独立方法总结必须使用五级或更高级的非题目标题。** 若只在答案后接普通文字，这些文字仍属于当前题目。题内需要小标题时使用六级，不能使用五级。

## 4. 小问与答案交替排列

支持并保留“小问后紧跟对应答案”。以下整体只有一道题：

```markdown
##### 例1 二次函数的最值与零点

已知函数 $f(x)=x^2-2x$。

（1）求 $f(x)$ 的最小值。

> [!answer]- 第（1）问解答
> 因为 $f(x)=(x-1)^2-1$，且 $(x-1)^2\ge 0$，所以当 $x=1$ 时，最小值为 $-1$。

（2）求方程 $f(x)=0$ 的解。

> [!answer]- 第（2）问解答
> 由 $x(x-2)=0$，得 $x=0$ 或 $x=2$。

> [!solution]- 补充说明
> 求最值使用配方法，求零点使用因式分解法。

##### 方法总结

这里是独立教学总结，不属于例1。
```

不把所有题干搬到一起，也不把所有答案搬到题尾。选择题、填空题、判断题按下节约定不写 `answer`；待作答练习也可以没有答案块，均为合法题目。

## 5. answer／solution 和双版本规则

### 5.1 按题型组织内容

| 题型 | 答案放置 | `solution` 内容 |
| --- | --- | --- |
| 选择题（单选、多选） | 在题干中用 `!{B}`、`!{ACD}` 标注，不写 `answer` Callout | 逐项判断依据、推导、排除理由等解析 |
| 填空题 | 在各空中用 `?{答案}` 标注，不写 `answer` Callout | 求出各空的推导、条件检查等解析 |
| 判断题 | 在各判断处用 `!{$\checkmark$}`／`!{$\times$}` 标注，不写 `answer` Callout | 正误依据、反例、错因等解析 |
| 计算、解答、证明及综合题中的相应小问 | `answer` 写标准解题步骤，即可直接写在学生答卷上的满分答案 | 按需补充方法选择、背景解释、易错点、另解说明等 |

选填判断的答案已在题干答案槽中，不另设汇总答案块；解析统一使用 `[!solution]- 解析`。解析中可以出现推导所得的结论，不必为避开重复而删去必要论证。

计算、解答、证明等题的 `answer` 应包含必要依据、列式、运算或论证、分类讨论、结论，以及适用时的取值范围、取等条件、单位等。不能只填最终结果或写“详见解析”，也不能把必需的得分步骤放在 `solution`。关闭教师版“显示 solution”后，`answer` 仍须独立构成完整的满分答案。无需补充时省略 `solution`，不留空块。混合题型按小问分别采用以上约定。

例如，证明题把完整论证放在 `answer`，方法解释放在 `solution`：

```markdown
##### 例2 正数不等式证明

已知 $a>0$、$b>0$，证明 $a+b\ge 2\sqrt{ab}$，并指出等号成立条件。

> [!answer]- 标准证明
> 因为 $(\sqrt a-\sqrt b)^2\ge 0$，所以 $a+b-2\sqrt{ab}\ge 0$，
> 即 $a+b\ge 2\sqrt{ab}$。
> 等号成立当且仅当 $\sqrt a=\sqrt b$，即 $a=b$。

> [!solution]- 补充说明
> 将待证不等式移项，识别为完全平方，可以把证明转化为平方非负。
```

### 5.2 双版本输出

需要隐藏的答案和解析块统一写 `-` 或 `+`，明确为教师专用；模板默认使用 `-`。

| 写法 | 学生版 | 教师版 |
| --- | --- | --- |
| `[!answer]-` 或 `[!answer]+` | 隐藏标准解答，生成对应实测高度的留白 | 显示完整满分答案 |
| `[!solution]-` 或 `[!solution]+` | 默认隐藏解析或补充说明且不留白；勾选“solution 留白”后生成对应空间 | 默认显示，可关闭 |
| 其他 `[!type]+/-` | 沿用教师专用块的等高留白规则 | 显示 |
| 无 `+/-` 的 Callout | 共享内容，直接显示 | 默认显示 |

**无 `+/-` 的 `[!answer]` 会在学生版显示，不能把它当成隐藏答案。** 无标记的 `solution` 在学生版仍为共享内容；教师版关闭“显示 solution”时会隐藏该类型。

Callout 类型及显隐选项不决定题目边界。嵌套结构必须写出引用层级；复杂跨层列表或省略 `>` 的懒续行，不属于全面保证范围。结构不一致时停止测量，不能猜测留白对象。

## 6. 选择和填空答案槽

```markdown
选择题答案：!{B}
多选题答案：!{AC}
判断题答案：!{$\checkmark$}、!{$\times$}
文字填空：?{正数}
公式填空：?{$\frac{1}{2}$}
```

`==重点==` 是普通高亮，不再是答案语法。不要沿用正式旧版的 `(==B==)`／`==42==` 作为开发版答案。

链接文字、资源地址、HTML 属性和原样代码区域中的答案标记按字面内容保留；需要隐藏的真实答案应写在这些区域之外。注释中的数学分隔符不参与后续答案和 Callout 的上下文判断。普通段落续行、基础列表续段中的答案槽仍会转换，真正的缩进代码和围栏代码保持原文。

公式内部语法 `$x=?{2}$` 与外层 `?{$x=2$}` 不同：前者只隐藏数值，后者隐藏整个等式。前者保留 A4 输出支持，但原生 Obsidian 阅读视图／实时预览的适配尚未全面完成，不能把二者混用作为替代。

字面量 `______` 可作为固定横线；它不是根据解答实测生成的书写空间。代码、公式和资源地址中的下划线不应被当成空白横线。

## 7. 数学、图片和引用

数学公式保持正常的 `$...$`、`$$...$$` 写法；显示公式前后留空行。图片保留原有 Markdown／Obsidian 引用和源文件相对上下文，不因分组改写地址。

题目起止信息在学生／教师转换之前产生，再映射到临时渲染 DOM；不会逐题切断文档重新渲染。全篇参考链接保持同一个 Markdown 解析上下文。实际 Obsidian 的脚注、嵌入、TikZ 与第三方渲染扩展仍需用原文验收。

## 8. 严格分页规则

一页指扣除页边距和页码后的实际 A4 版心。先等待字体、图片和公式稳定，再根据当前输出版本实测整题，不能用 Markdown 字符数量估算。

1. **整题不超过一页**：当前页放得下就原页放置；放不下就整题移至下一页。没有手动换页标记的短题绝不进入拆段回退。
2. **整题超过一页**：若当前页已有前题或正文，就在本题之前换页。已经位于新页时不额外增加空白页；第一页仅有总标题／版本抬头时允许在其后开始。
3. 长题从新页开始后，答案按完整段落、列表项等继续分页，避免把整个答案一股脑移到下一页。无法容纳的不可拆分公式或图片仍必须报告，不裁切。
4. 当前选择显示的 `solution` 参与教师版整题高度判断；学生版以实际生成的全部留白参与判断。
5. 学生留白不压缩、不删除。两版独立分页，可以页数不同。允许合理的空白尾页。
6. 题干本身超过一页时允许安全续页，不承诺物理上超高内容仍能同页。
7. **手动强制换页**：在顶层单独一行写 `------`，必须恰好 **6 个半角连字符**，后续内容从新页开始；可在题目中间使用，优先于整题同页规则，仍保留同一道题的范围与编号。顶格书写，行末可有空格；`---`、`-----`、`-------` 或分散写的 `- - -` 不触发手动换页。代码、引用／Callout、数学块、注释、HTML 块、YAML 内的同样文本不触发。开头、连续和末尾标记不额外生成空白页。原文、学生版、教师版 A4 预览和 PDF 使用同一规则，保存的 HTML 也保留打印换页语义，源笔记不会被改写。

```markdown
第一页内容。

------

这里从新页开始。
```

文件夹组卷和单题卡沿用一题一容器，不要求卡片另加五级标题；也执行短题不拆、长题新页开始。

## 9. 预览与诊断

- **显示题目范围**：在 A4 预览克隆上显示边界细框，不改变布局高度、不打印到 PDF。悬停可查看题名和源码行范围。
- **复制题目边界**：复制识别题目、源码起止行、边界提示及每题实际开始／结束页。
- **将当前题标设为五级题目标题**：在明确的“例1”“变式1”“第1题”等当前行上执行；只在用户主动执行命令时修改这一行，不批量猜题，不在导出时修改文件。

遇到孤立 `answer`、错误标题级别或旧式题标，会显示未受整题保护的提示。无题标且无答案的普通段落不一定能被认定为漏题，必须检查题目范围。

空题、边界标记丢失、标题顺序或渲染层级与源码不一致时停止严格分组。预览分页失败可显示连续内容供诊断，但 PDF 仍需通过同一分页器，不能假装严格分页已通过。

## 10. 迁移与兼容

旧讲义不自动改写。将每道题的原题标改为 `##### 例1` 等；将题内小标题改为 `###### ...`；独立总结改为 `##### 方法总结`。原有题干、小问、答案、公式和图片内容不需要挪动。

调整旧答案分区时逐题核对：选填判断的最终答案保留在 `?{}`／`!{}` 中，把原 `answer` 中的推导及解释并入 `solution`，去掉重复的答案汇总块；计算、解答、证明等题则把必要作答步骤归入 `answer`，仅将补充说明留在 `solution`。不能仅按 Callout 名称全篇替换。

推荐先保存副本，再使用命令逐题转换，开启题目范围核对后输出 PDF。前三四级标题可保留作为章节／题型层级，但不再作为题目起点。

本规范对应开发版，自动化和真实 Chromium 测试不等于完整 Obsidian 宿主、跨主题、跨操作系统验收。

## 11. 题卡元信息与模板验收

普通讲义不要求 YAML；单文件题卡用于文件夹组卷时，以以下字段为准。复制模板必须替换示例 ID，并核实实际来源。已有知识点仅迁移字段，不从题名或路径猜造知识点、章节或题族身份。

| 字段 | 用途／值 |
| --- | --- |
| `object_type` | 题卡使用 `question` |
| `question_type` | `choice`、`multiple_choice`、`fill_blank`、`true_false`、`short_answer`、`calculation`、`proof`、`comprehensive` |
| `knowledge_nodes` | 知识点列表，保持项目原有标识或链接；未知用 `[]` |
| `teaching_tier` | 原有教学分层，如核心、基础、培优、扩展；不自动重定级 |
| `difficulty` | 1～5；与教学分层独立 |
| `role` | 已确认的 `example`、`variant`、`practice`、`homework`、`test`；未知用 `null` |
| `source` | 实际来源；未核实应注明，不把示例“原创”当作事实 |
| `chapter_id`、`section_id` | 已确认的章节身份；未知用 `null` |
| `family_id`、`parent_id`、`question_group_id` | 已知结构关系；没有依据时用 `null` |
| `methods`、`assets` | 方法和资源列表；未知用 `[]` |

旧模板中的 `知识点`、`level`、`来源` 分别迁移为 `knowledge_nodes`、`teaching_tier`、`source`。`type` 题型别名仍兼容，但新模板统一写 `question_type`，不保留相互冲突的双字段。

空值必须写未加引号的 `null`／`~` 或留空；`"null"` 是文字。缺少章节、教学角色等信息会继续产生审计提示，不能为了消除提示编造身份。Obsidian 中优先使用宿主解析的 YAML；离线后备读取只支持项目所需的简单标量和列表。

模板自动验收检查题目数量、边界警告、学生答案投影、正式字段和交付清单链接；它不能证明数学内容正确。完整题卡应写可核算的答案；占位教学内容应明确标注并在实际使用前补齐。
