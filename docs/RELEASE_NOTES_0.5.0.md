# Mathsemble 0.5.0

在“选材与编排”的题目页可以只选章节，也可以继续选小节。知识点列表会随范围收窄，直接选知识点仍可跨章节查题。题卡已有的章节字段和题库的章节目录都可以用于筛选。

## 大题库选材

- 提前建立知识笔记的查找索引，加快全库知识点筛选。选择章节或题型时可直接匹配题卡属性。
- 同一次 Obsidian 会话中，再次打开或刷新选材页会复用浏览索引。题卡发生变化后，刷新时只重新读取受影响的文件，并更新题目之间的关联。
- 点击“再显示 100 条”会追加下一批题目，前面已经显示的公式预览可以继续使用。

在同一份含约 2.3 万道题、393 篇知识笔记的本地快照上，构建核心索引由约 30 秒缩短至约半秒。一个命中 23 道题的全库知识点查询由约 19 秒缩短至约 20 毫秒。七组条件返回的题目及顺序逐项一致。计时覆盖索引和查询计算，首次读盘、解析文件和界面绘制另计。

## 从 0.4.0 升级

备份插件目录和组题方案，将本发布页的 `main.js`、`manifest.json` 和 `styles.css` 放入现有 Mathsemble 插件目录，然后重新加载插件。原题卡和 v1 至 v4 组题方案可直接打开。恢复 0.4.0 时，可换回备份的三个插件文件并重新加载。
