## 数据与兼容性

- 原 Markdown 题卡保留平面字段，无需迁移。`family_id` 仅去首尾空白并精确匹配；缺失、null、空白不合并为空题族。`parent_id` 只核验显式引用，不从角色或同族推导母题，不回写原卡。
- 方案仍读 v1／v2／v3，显式保存 v3。不增加蓝图、锁定、归档等未知字段；换题仅更新目标的三项来源引用，保留 `entryId`、顺序、标题、角色及其他设置。基线 0.2.5 旧 core 另行核对可读取规范化后的 v3；正式 0.2.4 原有“不读 v3”的边界保持。
- 独立 schema 1 蓝图位于 `Mathsemble/组卷蓝图/`，包含稳定蓝图／行 ID、修订、条件、数量与题族上限。独立运行记录位于 `Mathsemble/组卷记录/`，包含蓝图快照、前后方案摘要、种子、算法、逐槽归属、真实锁定与来源摘要。
- 运行记录按严格方案摘要匹配。已知记录失效时拒绝换题，不放宽条件；多份匹配记录须明确选择。显式解锁只影响目标槽，新结果保存为新记录，旧记录不覆盖。无有效匹配记录的旧方案明确显示历史配额未知。
- 每次导出记录来源和产物事实；可选归档保存当次已捕获原文、资源、方案和产物。**归档包含教师答案和隐藏媒体**，不嵌入学生 PDF／HTML；目前不是一键可回导的题库包。
- 方案与配额记录分两次写入。记录失败时保留方案已保存事实，可在当前工作区重试；待保存记录只在该工作区内存中，关闭或重启后不自动恢复。
