# 0.2.0 知识点与组题测试说明

日期：2026-11-05。状态：开发测试候选，尚未发布正式 Release。三个安装文件的摘要见 [SHA256SUMS](../release/SHA256SUMS.txt)。源码恢复来源见 [基线说明](BASELINE_0.2.0.md)。

## 试用流程

1. 解压测试包，将 `mathsemble/` 文件夹放入独立测试库的 `.obsidian/plugins/`，重启 Obsidian 并启用 Mathsemble。不要同时启用两份不同目录名的 Mathsemble。
2. 运行命令 **知识点与组题工作区**。展开“内容目录”，分别设置题库、知识库目录，每行一个库内相对路径，然后应用扫描。
3. 选择一篇知识笔记，预览并点击“整篇加入”；再加入两道题。检查知识正文、公式、图片和题目关联是否正确。
4. 添加分区，拖动排序，修改本次显示标题及例题／变式／训练角色。生成 Markdown 后检查顺序与标题；源笔记不会随编排修改。
5. 保存方案、另存方案，并重新打开检查。修改一个来源后重新扫描，确认出现更新提示；显式更新引用后重新生成。删除来源或制造重复 ID 应阻止生成。
6. 点击“A4 预览 / PDF”，核对学生版／教师版及打印。此按钮先在 `Mathsemble/讲义/` 保存一份当前 Markdown 快照，再打开原有预览；每次生成独立文件。

方案保存为 `Mathsemble/组题方案/*.json`。含唯一 ID 的来源可随改名继续定位；无 ID 的来源按路径定位，改名后需重新加入。整篇知识默认保留全部正文；首版不做小节截取、自动抽题或自动补标签。同一来源在一个方案中只能加入一次。

Markdown 笔记嵌入需要先展开正文，缺失的本地图片会阻止生成；这两种情况都有明确提示。题目内部标题生成到 H6，知识标题调整到 H2–H4，避免与 H5 题目边界混淆。外部资源仍遵循原导出流程。
