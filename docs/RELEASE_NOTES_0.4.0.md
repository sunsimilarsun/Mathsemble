# Mathsemble 0.4.0

0.4.0 支持把题卡引用直接编成讲义，手写题与整题引用按出现顺序连续编号。学生版和教师版的每道题都从题号和题干开始。教师仍可在编排中查看题名、来源、角色和分值。

## 备课与组卷

- **引用题卡或保存展开副本。** 在“选材与编排 → 方案操作”选择“保存讲义（引用题卡）”。整题保存为独立一行的引用，知识和所选片段直接写入讲义。重新读取引用讲义即可纳入题卡已保存的修改。需要保留当时的完整正文时，选择“保存展开副本”。[讲义混排写法](https://github.com/sunsimilarsun/Mathsemble/blob/0.4.0/docs/MARKDOWN_SPEC.md)
- **查找、替换和排序。** “查看题族”定位到全部同族成员。“找相似题”可按同族、同考点或同方法查找并查看匹配依据。编排中可以原位换题，继续遵守配额、锁定和题族上限。“预览编排”的右侧排序目录可定位正文、拖动题目或移动整个分区。[相似题](https://github.com/sunsimilarsun/Mathsemble/blob/0.4.0/docs/SIMILARITY.md) · [排序目录](https://github.com/sunsimilarsun/Mathsemble/blob/0.4.0/docs/ASSEMBLY_ORDERING.md)
- **选取小问与知识小节。** 有稳定锚点的材料可以选择部分内容，保留共用题干、所选小问的解答及图片。整题和所选小问可在方案内设定分值。未带锚点的旧卡继续整篇使用。[片段与分值](https://github.com/sunsimilarsun/Mathsemble/blob/0.4.0/docs/ASSEMBLY_FRAGMENTS.md)

## 授课与题库管理

- “逐题投影”从当前编排逐项展示。揭示答案只影响当前项，翻页后重新隐藏。“实际使用账本”按班级或课程登记已讲、已布置的材料，供下次选材时筛选。教师主动登记才会计入使用次数。
- “题库诊断与入库”检查身份、缺失资源及疑似重复。导入 Markdown 或受支持的结构化 JSON 时，先核对候选、路径及 ID 映射，再确认创建。材料包可携带方案、源文及已捕获的本地资源，回导同样先进入待确认批次。资源缺口会列在报告中。
- 修复导出时响应式图片选错版本或 SVG 丢失视图定位、编辑配额蓝图时部分条件未保留等问题。

## 从 0.3.1 升级

1. 备份原插件文件、组题方案、使用账本、入库批次与导出归档。将发布页中的 `main.js`、`manifest.json`、`styles.css` 放入 `<vault>/.obsidian/plugins/mathsemble/`，重启桌面版 Obsidian。插件 ID 和最低宿主版本（1.5.0）沿用原设置。
2. 旧题卡和 v1–v3 方案可直接打开。整篇选材且未设分值时，保存仍使用 v3。首次给旧方案设置分值或选择片段，请用“另存方案”创建 v4 并保留原文件。
3. 若需要回到 0.3.1，可在 0.4.0 中清除方案里的全部分值、把片段切回整篇，再另存 v3。使用依赖新编号规则的讲义时，可先导出学生版和教师版 PDF，保留本次版面。

## 导出验证

发布构建在 Windows 通过 1087 项自动测试。使用相同主程序和样式在桌面版 Obsidian 导出混排讲义，两版 PDF 都能连续读回 58 个题号。学生版保留 58 处作答留白，教师版显示 58 个对应答案。
