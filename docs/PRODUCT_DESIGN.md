# Mathsemble 产品流程与设计边界

适用版本：0.2.4 开发版。本文说明当前流程、编辑对象和保存范围；实现与验证状态见[功能矩阵](FEATURE_MATRIX.md)，内容语法以 [Markdown 规范](MARKDOWN_SPEC.md) 为准。[旧版 FRD](REQUIREMENTS.md)保留历史，不作为当前功能状态。

## 主流程

Mathsemble 是以 Obsidian Markdown 为来源的数学备课、编排与双版讲义输出工具。

- 从素材备课：题卡／知识笔记 → 选材 → 预览编排 → 临时 A4 排版与导出；需要 Markdown 时另行保存讲义副本。
- 已有讲义：打开已保存的 Markdown → A4 排版与导出。
- 当前题卡、当前文件夹组卷是快捷入口，共用排版与输出能力。文件夹快捷组卷只读取当前层，与跨目录选材分开。

| 界面 | 主要任务 | 常用操作 |
| --- | --- | --- |
| 选材 | 判断哪些内容适合这次课 | 筛选、每项一行预览、查看全文、加入编排、生成候选 |
| 预览编排 | 安排本次课的内容顺序与用途 | 连续阅读、单项或整分区排序、修改本次标题／角色、添加分区、打开原文 |
| 排版与导出 | 检查最终页面并保存文件 | 选择内容版本、外观、留白、试听信息，查看诊断，保存 PDF／HTML |

生成候选不会直接改方案，点击“加入编排”后才加入。候选不足不自动放宽条件；来源变化、缺失或身份冲突需处理后再预览 A4 或保存讲义副本。

编排是有序的题目、整篇知识与分区标题。一个分区包含标题及其后直到下一个分区之前的题目和知识；所属范围按当前顺序确定，无需增加嵌套方案格式。题号只统计题目；普通题目和知识的编排位置包含所有项目，分区移动使用分区序号。题干修改通过“打开原文”完成，本次标题与角色调整不回写题卡。

分区的上下箭头交换前后完整分区，拖动分区手柄会带上其全部内容。拖到另一分区任意内容上时，向下移动放在目标分区之后，向上移动放在目标分区之前，不拆开目标分区；“更多”可按分区序号指定位置。空分区可移动，首个分区之前的前言保持在开头。普通题目和知识仍单项移动；“移除分区标题”保留其正文。移动只改变方案顺序，保留来源身份、引用版本、本次标题、角色、课程和排版设置。

## 三个独立选择

| 维度 | 选项 | 含义 |
| --- | --- | --- |
| 教学角色 | 例题、变式、训练 | 本次教学用途，不决定答案显隐；当前没有母题与变式的关联编排模型 |
| 内容版本 | 学生版、教师版；长讲义另有原文预览 | 根据明确答案标记决定显示、隐藏和留白；原文预览不转换答案 |
| 排版外观 | 默认、双列、试听 | 页面结构，与学生／教师版本独立选择 |

无教师专用标记的 Callout 属于共享正文，不能仅凭角色或颜色隐藏答案。直接打开长讲义默认进入原文预览；从编排生成时使用方案的默认版本，新方案默认为原文预览。题卡与文件夹组卷默认进入学生版。

## 编辑与保存范围

| 对象 | 内容 | 保存及更新规则 |
| --- | --- | --- |
| 原笔记 | 题干、答案、解析、知识正文及源属性 | 在 Obsidian 中编辑并保存；编排和输出不回写。专门的题标／教学角色命令会按用户操作修改源文件 |
| 素材索引 | 本次扫描的正文、元信息、来源标识及变化状态 | 刷新素材重新读取；不是持续同步的独立内容库 |
| 候选 | 当前条件与数量生成的待选题目 | 不随方案保存；筛选、数量、扫描或实际方案修改后需重新生成 |
| 编排方案 | 讲义标题、有序来源引用、本次标题和角色、分区、课程信息与默认排版设置 | 显式保存到 `Mathsemble/组题方案/`；不保存题干 |
| 本次排版设置 | 内容版本、外观、留白、显示字段、试听信息 | 从方案进入时恢复默认设置；调整后显式应用到编排草稿，再保存方案。直接打开文档时仅当前窗口使用，不写回 Markdown |
| 临时 A4 预览 | 打开时的编排、课程设置及来源正文快照 | 仅在内存中使用，不创建或读取中间讲义文件；来源变化后失效，回到编排核对后重新打开 |
| 讲义副本 | 保存当时的正文副本 | 通过“保存讲义副本”写入 `Mathsemble/讲义/`，每次保存新文件；已有副本不随原笔记变化 |
| PDF／HTML | 本次排版的输出结果 | 保存到 `ExamExports/`，不随来源自动更新；PDF 可在系统阅读器中打印 |

Obsidian 可恢复工作区草稿，这不等于已显式保存方案。标题／角色在加入时可从原笔记复制；接受来源更新保留本次覆盖值。选择“沿用题卡”或清空本次标题时，生成会使用对应的来源值。

“预览 A4”直接使用当前编排准备临时内容，不新增 Markdown，也不自动保存方案。准备期间更换、修改或关闭原编排工作区，旧预览不再打开。“保存讲义副本”是编排中明确创建 Markdown 的操作，不打开排版界面；反复预览不会生成重复文件。

试听课题仅读取 `titile`，教师读取 `author`，教师缺失或空白时为“孙老师”，其他缺失信息留空。编排方案保存独立的课程信息。课题默认跟随讲义标题，也可单独填写或主动留空；生成时明确写入 `titile/author` 和其他课程属性，不把题卡属性汇总为课程属性。直接打开已有文档仍严格按原属性读取，不用普通 `title` 或文件名补课题。

## 方案设置的恢复与应用

“方案操作 → 课程与排版”修改草稿，显式保存后保留课程信息、默认版本、外观、留白比例／最低高度及学生解析留白／教师解析显示选项。元信息显示字段只属于题卡与文件夹快捷模式，不在讲义编排方案中保存。

从方案进入 A4 后，调整不会自动回写；点击“设置 → 应用到编排方案”只更新原工作区草稿，还需保存方案。工作区关闭、忙碌、方案更换或另有修改时拒绝旧窗口回写；同一窗口成功应用后可以继续调整并再次应用。已有讲义副本不更新，需要再次生成。

课程标题用内部 `null` 表示跟随讲义标题，字符串空值表示有意留空；未编辑的 A4 课题不会把继承关系改成固定标题。教师为空时生成 `author: 孙老师`。警告确认、跳过内容许可、诊断状态和输出结果不写入方案。

旧 v1 方案读取时只在内存补默认设置，显式保存后写为 v2；旧插件会拒绝 v2 方案，避免遗漏新设置。外部修改冲突检测继续使用真实文件内容。

## 刷新与定位

| 操作 | 实际更新对象 |
| --- | --- |
| 刷新素材 | 重新读取题库与知识库，显示来源变化；不自动接受方案引用的新版本 |
| 接受来源更新 | 刷新后接受可解析来源的新版本和路径，保留本次标题／角色；缺失、冲突不自动替换 |
| 重新排版 | 按当前内容和设置重新渲染，不重新读取文件 |
| 重新读取源文 | 读取已保存的当前文档；文件夹模式重新读取当前层题卡，成功后整体替换内容 |
| 返回编排更新 | 从临时 A4 回到原工作区；保留当前草稿，由用户刷新、核对并按需接受来源，再重新预览 |
| 定位原文 | 临时 A4 指向原题卡或知识笔记，可靠匹配时定位到行，否则打开对应源文件；普通文档只定位本次读取的文件 |

临时 A4 保存来源快照，并在打开期间监视所配置题库和知识库目录中的 Markdown 变化。新增、修改、删除或改名会保守地使旧预览失效并阻止导出，即使变化不属于本次已选内容。刷新和接受来源只在编排工作区完成，A4 不静默读取新正文或接受新版本。

“返回编排更新”只显示原工作区，不恢复打开预览时的旧草稿、不接受来源、不保存方案。原工作区仍存在但方案已经更换或修改时保留现状并提示核对；原工作区关闭后提示重新打开方案。

已保存讲义副本单独打开后使用普通文件流程，读取、监视和诊断定位均针对该副本，不汇总上游素材。普通文档重新读取时保留当前排版偏好及手动修改过的试听字段；未保存的源文编辑不进入预览。

## 状态与输出

方案保存状态、来源状态和排版状态分别表达，不能用“已保存”代替“可输出”。

- 编排：方案未保存／已保存；来源待核对／有变化／缺失或冲突。来源状态反映最近一次读取结果，不代表实时监视。
- 临时预览：使用打开时的来源快照；来源目录内 Markdown 变化后需返回编排核对并重新预览，不能仅重新排版后继续输出。
- 排版：正文渲染、A4 分页与输出检查分别判断。分页失败时即使连续正文可见，也不代表 PDF 已通过检查；需修复或在输出时重新核验。
- 输出：当前版本 PDF、学生版和教师版 PDF、HTML 备用文件。当前没有直接系统打印按钮，保存 PDF 后使用阅读器打印。

局部渲染警告的确认仅按现有规则作用于当前单版；结构、留白和真实溢出错误仍阻止 PDF，双版不继承单版的不完整输出确认。两版先完成生成再保存，但写文件可能部分成功，结果按实际保存情况报告。
