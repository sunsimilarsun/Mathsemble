# 题干—答案成组分页（0.1.12 开发候选）

## 规则

1. 能放进一整页的题组（题干、题图、answer，以及当前选择显示的 solution）优先保持同页；当前页不足时整组移到下一页。
2. 如果是较长的 solution 导致整组超过一页，优先保留题干与完整 answer 同页，solution 单独续页。
3. 题干加 answer 本身超过一页时，将题干与 answer 标题、首个完整步骤绑定；剩余解答利用当页剩余空间，按段落或列表项继续分页。后页使用“（续）”标题，保留同色四边框。
4. 学生版将完整题干与第一段真实留白绑定，其余留白继续分页。保留留白总高度和原有分段数，不能通过压缩留白满足同页要求。solution 是否留白仍由独立选项控制。
5. 当“题干 + 首步”自身就超过整页时，优先保留题干最后一块与首步同页，并在分页报告和状态区记录放宽约束；不能承诺物理上超过一页的内容仍同页。单个不可拆分图形、公式或超高步骤仍报错，不能裁切或丢失。

## 单文件讲义的分组边界

- 识别 Markdown 标题或独立段落中的明确题标，例如 `例1`、`例一`、`【例题1】`、`变式一`、`练习1`、`检测1`，以及明确的编号题标。
- 新题标、一般章节标题、水平分隔线、答案后的普通正文会结束当前题组；不把相邻题目或方法总结合并。
- 没有明确题标时，仅绑定紧邻答案的题干段落、独立公式/题图/选项，或单项编号题目。不能从任意散文自动可靠猜出多段题干的起点。
- `(1)`、`（2）` 等小问序号不是新题边界。
- 文件夹组卷继续利用已有题目容器，不依赖题标猜测。
- 此轮不把复杂嵌套列表里的任意长题、跨层 Callout 或任意 HTML 视作已全面支持；不能无依据把多个普通段落认定为同一题。

## 数学与源码不变

分组发生在已渲染 DOM 上，不改写 Markdown、答案语法或 YAML。MathJax SVG、图片与公式节点直接移动，不重新排版 TeX。答案中的引导句及紧随的独立公式尽量作为同一步；列表按完整 `li` 拆分，并保留续页编号。

预览与导出使用同一个分页器。失败的试排必须恢复节点顺序，避免后续尝试丢失、重复或错序。

## 诊断

新增 `handoutGroups`、`intactHandoutGroups`、`keptPromptAnswer` 和 `relaxedGroupBindings`。保留整题、学生留白、页数及溢出核验字段。允许合理的空白尾页，不为了省纸删除作答空间。

## 验证边界

`tests/question-answer-groups.test.cjs` 使用真实 Chrome/Chromium 与实际打印 CSS，覆盖短题整组、长答案、长 solution、学生留白、多题边界、列表续号、MathJax SVG、预览/打印分配一致性与不可拆分对象错误。通过 `CHROME_PATH` 可以指定浏览器；CI 不允许无浏览器而静默跳过。

自动回归和独立 Chromium PDF 验证不等于真实 Obsidian 跨主题、跨系统验收。0.1.12 仍为开发候选，不创建正式 Release。
