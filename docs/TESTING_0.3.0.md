## 数据兼容与教师资料边界

方案继续读 v1／v2／v3、显式保存 v3；未增加 `planId`、蓝图、锁或归档字段。蓝图和配额记录为独立 schema 1 JSON。基线正式 0.2.5 core 已另行核对可读取保留原结构的 v3；正式 0.2.4 不读 v3 的既有边界不变。源题卡未批量迁移，未自动补写 `family_id` 或 `parent_id`。

方案与配额记录不是文件系统事务：方案已保存、记录失败时不能回滚已保存事实；当前工作区保留待保存记录供重试，但关闭或重启后不自动恢复该内存状态。已有记录失效时拒绝受约束换题，不因错误转为普通无约束模式。

**教师材料归档包含完整原文，可能包含答案、解析和学生页面不可见的媒体。** 学生 PDF／HTML 的投影与归档独立，分发时只选核对后的学生产物。轻量记录可能包含源路径、标题与配置，也应留在教师侧；它不保存原文和媒体全文。

归档 `complete` 只覆盖本次捕获输入和已观察资源，不等于所有输出都保存成功。未支持嵌入、SVG 外链、库外未复核文件等保留明确缺口；默认会话预算为 64 MiB 去重资源字节，不代表全部运行内存或 PDF 体积上限。归档保留原文引用并另存媒体映射，目前不是一键回导包，也不保证未来环境位级重现 PDF。详见 [媒体归档说明](EXPORT_ARCHIVE.md)。

## 尚未覆盖的范围

- 本轮原生验收限 Windows；没有 macOS 原生重验或实体打印确认。
- 没有穷举所有第三方主题／渲染器、真实远程服务故障或宿主崩溃恢复。自动故障注入与原生故障实测分别看待。
- 阅读公式内部答案槽仍有既有边界；相同转义与真实可见拼写采取保守处理。双列宽矩阵可能分行，复杂 PDF 文本提取顺序不能替代图像核验。
- 合成样例和软件流程验证不代表整个教学库数学审校、个人材料迁移或真实课堂效果通过。
- 版本更新、远端 CI、发布资产、备份及教学插件更新须按上方状态表填写实际结果，不能从阶段原生证据推断完成。
