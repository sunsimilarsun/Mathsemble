# 相似题：本地检索与受约束换题

本功能在现有题卡、题族与组卷流程上增加三个模式：同族、同考点、同方法。检索结果是供教师核对的相关候选，不证明数学等价、解法一致或教学效果相同。

## 使用

- 在选材页题卡上点击“找相似题”，选择三个模式之一并点击“刷新候选”，阅读共同标签、难度与缺失信息，并预览或打开源文。切换模式后须重新刷新。
- 在编排项“更多”中点击“相似换题”，核对采用的配额记录与筛选。锁定题须显式解锁；没有匹配记录时不推断历史配额。
- “查看题族”和“同族换题”保持原有语义。相似题检索不会建立或更改题族、母题或知识点关系。
- 选用后保留编排项身份、位置、卷内标题与角色。P2 整题分值继续保留；选用了稳定小问的编排项须先切回整题，不能把另一题的片段身份套用过来。

## 数据与解释

检索使用已有的 `knowledge_nodes`、`methods`、`family_id`、`subject`、`question_type`、`difficulty`、`teaching_tier` 和兼容字段。0.4.0 可继续读取 v1 至 v3 方案。使用分值或稳定片段的方案保存为 v4。[方案兼容说明](ASSEMBLY_FRAGMENTS.md)

`family_id` 仅去首尾空白、区分大小写；未归族题不共享一个空题族。`parent_id` 只解释显式关系，不从角色或同族推断。

知识点、方法的规范化在派生索引内完成，保留原始表示与解析状态。可以利用已有词表的规范 ID、名称和别名；名称歧义、学科范围不符和无法确认的引用不自动合并。共用一篇知识笔记不等于共享每个细分考点，目录分组也不当作知识图谱。

旧题卡中的简单 `[[标签]]` 即使没有目标页，也可以按同名声明参与比较，并提示链接未解析；不据此推断同义词。无法解析的路径、锚点及已知歧义引用不会降级成普通标签。

无方法、知识点的旧题仍可参与明确的同族查找。缺少对应模式证据时显示原因，不用空标签补出结果。难度未知不按 0 处理；教学层次与难度分别显示。通用 `tags`、来源和“例题／训练”等角色不充当数学相似证据。

## 检索与排序

同族模式按显式题族召回；同考点、同方法模式分别依据规范标签召回。宽泛方法需要额外的考点证据。先过滤身份冲突、原题及已知学科不符的题，再在候选中排序，不建立全库两两相似矩阵。

题干特征排除 frontmatter、答案／解析及通用教师内容，答案槽保留问题位置并去掉答案。数字、符号、量词等差异保留。文字特征只辅助排序，不执行代数等价证明、图形识别或生成新题；图片主导题会有文字证据不足提示。

初始排序权重：同考点模式知识点 0.60、方法 0.25、题干 0.15；同方法模式交换知识点与方法的权重。标签使用加权集合重合度，题干使用稀疏向量接近度。缺失维度不补满权重，结果同时提供理由与缺失信息。分数不是概率，不以“相似百分比”表示数学等价。

本期不调用外部模型、联网上传题目或依赖向量数据库。索引是可重建数据，人工维护的词表与映射不是可随意清理的缓存。

## 换题约束

浏览和替换是两个动作。能找到的相关题不一定满足当前试卷的配额；替换须保留原配额行条件、锁定、已选题排除与全卷题族上限。跨族替换先扣除原题所在族，再计入候选所在族，核验整个方案。

题型与难度不是默认硬限制；仅在启用对应素材筛选或配额行限制时约束候选。“难度相邻”是解释信息，不自动施加难度差不超过 1 的筛选。

应用前重新读取来源与词表，核对方案、目录、约束和候选是否仍有效。界面不能通过修改候选对象、放宽筛选或选择旧候选绕过验证。来源变化时要求刷新，不自动接受变化或写回题卡。

已知配额记录产生新的替换记录，旧记录保留；推荐解释不扩充方案协议。P2 使用账本、课堂展示或保存记录不参与推断学生掌握程度。

## 验证边界

纯算法测试、服务校验测试、Chromium 界面交互与原生 Obsidian 验收分别记录。合成题与边界样本验证检索规则和兼容性；它们不代替教师对实际题库推荐质量的评价。具体执行结果见 [测试记录](TESTING_SIMILARITY.md)。
