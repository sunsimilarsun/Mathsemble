# Mathsemble 功能需求规格说明（FRD）

- 版本：**v0.1.9 文档基线 / FRD 1.0**
- 日期：**2026-10-23**
- 适用范围：Obsidian **桌面端**、本地 Markdown 题卡与讲义、学生版／教师版 A4 PDF／打印
- 代码依据：本地 `Mathsemble_v0.1.9_局部渲染警告_可继续PDF打印_直接安装包.zip` 内的 `main.js`、`manifest.json`、`styles.css`
- 状态口径：**L=本地包存在代码实现；V=静态／局部自动化验证；H=真实 Obsidian 宿主／PDF 验收；P=规划**。L 不代表 H；本仓库当前不含完整源码及正式 GitHub Release。

## 1. 产品目标与非目标

### 目标

使用**单份 Markdown 原文**生成讲义或试卷的学生版与教师版，尽量保留排版、公式、题图、题目顺序与答案结构。学生版根据教师专用块的真实渲染高度安排完整书写空间。以**可诊断、可核验、可选择性容错**的打印管线代替“一处公式失败即整份无法输出”。

### 当前不做

- 不以完整 LaTeX 编译器取代 Obsidian Markdown/MathJax。
- 不自动编造、更改题干、答案、来源、题族关联、学情信息。
- 不使用 AI 自动改题作为 PDF 输出的隐式前置条件。
- 不将剪裁、缩小全部公式或清空学生答题空间作为规避报错手段。
- 不把本地实验代码的存在等同于完成跨平台／真实打印验收。

## 2. 固定语法及兼容性契约（P0）

### FR-01 Callout 的显隐与留白

解析规则：`> [!type]` 后紧贴 `+` 或 `-` 的整个 Callout 为**教师专用**；**不带** `+/-` 的整个 Callout 为**双版共用**；无论 `type` 是 `answer`、`scaffold`、`note`、`success` 或自定义名称，规则相同。

- 教师版：显示所有教师专用及共用 Callout 的完整内容。
- 学生版：按原顺序把每个教师专用 Callout 替换为**对应高度留白**，保留共用 Callout。
- 原文预览：不转换答案和内容；用于检查 Markdown 原有呈现。打印副本可临时展开 Callout，不回写源文件。
- `+/-` 不再被赋予两种不同的打印权限；Obsidian 正常阅读时的展开／折叠表现不受 Mathsemble 强制更改。
- 教师块计数与学生留白槽按**全部 Callout 的出现顺序**建立可靠映射；不能只按 `answer` 类型匹配。

**验收**：同一讲义混合 `answer-`、`scaffold+`、`note-`、`student-note`、无标记 `answer`，检查两版每块可见性、顺序、位置、数量；教师 4 个专用块 → 学生 4 个留白槽；共用 Callout 在两版中完整显示。

### FR-02 等高留白与分页

- 先实际渲染完整教师版，在**相同版心宽度与排版样式**下测量目标 Callout 的外部高度，再投影学生版留白。
- 默认 `ratio=100%`、`minimumCm=0`；预览调整选项为 50/75/90/100/110/125/150% 和 0/2/4 cm；调整后重新测量／核验。
- 长留白允许拆为不改变总高度的连续分段并跨页，保护题目与作答区域的逻辑顺序。
- 留白缺槽、计数不匹配、零高度、累计高度不一致时 **阻断 PDF**。
- 默认高度须与测量教师内容一致（容差以实际像素审计为准）；人为调整比例时，报告应反映真实设置。
- 学生卷或试卷**最后存在空白页可以接受**；不能仅为删除尾页而削减答题空间。

**验收**：单行、公式块、长推导、多层列表、含图、跨页答案各至少一例；输出教师高度、目标留白高度、学生预览实测高度及分页后结构报告；真实 PDF 另做可视校验。

### FR-03 选择／填空答案槽

- `(==任意内容==)` / `（==任意内容==）` → 选择答案（可以为多字母），学生卷隐藏答案且**不画填写下划线**。
- `==任意内容==`（没有紧贴的外部圆括号）→ 填空答案，学生卷隐藏答案并保留填空横线／占位；教师卷显示参考答案。
- 分类**不看答案内容，也不被 YAML `question_type` 覆写**；支持中文／英文圆括号及贴近答案槽的空格。
- 对数学环境、代码围栏、转义及 `==`／`$` 嵌套采用保守转换；不允许错误修改 LaTeX 数学表达式。

**验收**：`(==B==)`、`（==BC==）`、`==$x^2$==`、`==42==`、行内数学混合、代码块、转义、非法未闭合标记；验证正确分类、隐藏与不误改。

### FR-04 数学与图像排版

- 支持 Obsidian MarkdownRenderer + MathJax 的常见数学排版；尊重换行的 `aligned`、`cases` 与公式环境。
- 检查**版心左右越界**、祖先容器水平／纵向裁切；不能因 `overflow` 属性存在就错误认定被裁切。
- 导出时确保已折叠 Callout 的内容可见再测量；区分“因不可见容器导致零尺寸”与“MathJax 尚未排好版”。
- 图片应等待加载；TikZJax 依赖外部环境，不能承诺所有 TikZ 代码可自动转换 SVG。

**验收**：短公式、超宽连等式、未闭合括号／花括号、多个折叠 Callout、显式 `overflow-x:hidden`、嵌套 CSS、图片失败、TikZ 缺依赖。

## 3. 渲染容错与输出安全（P0）

### FR-05 渲染问题分类

| 类别 | 场景 | 预期 |
| --- | --- | --- |
| 正常 | 全部解析／布局成功 | 直接开放保存／打印 |
| **可恢复警告** | 个别 MathJax 语法错误、局部图片未加载、TikZ 未生成；其余正文仍可用 | 列明错误及内容不完整风险，须**明确勾选确认**后继续 |
| **阻断错误** | 无有效正文／页面、公式真实越界或裁切、不可见布局导致有效内容无法测量、教师块／学生留白计数和高度异常、有效分页失败 | 停止 PDF／打印；确认按钮不得绕过 |

- 同一失败不得在“预览 → 导出前复检 → 独立打印窗口”阶段被反复误拦截。
- 用户确认只适用于**已经展示过的错误类别**；打印窗口额外出现的新类型错误仍须阻断。
- 每次切换学生／教师／原文模式后清除旧的导出确认，避免误复用。
- 保存后状态信息须显式说明“带 N 项局部警告／内容可能不完整”；不宣传其数学内容已完整验收。

**验收**：1 个 `Missing close brace` 与其余 99 个正常公式同时存在时，产生可勾选警告且可导出；未勾选时不得导出；真实超宽公式、0 高度教师块和丢失题干时，即使勾选也不得导出。

### FR-06 可操作错误报告

- 显示公式编号、所在题／Callout、附近文字、MathJax 错误（如 `Missing close brace`）。
- 提供“复制渲染错误详情”供定位；多项相同根因应汇总，不刷屏数百条。
- 删除与当前错误无关的固定 Q07／U+000C 提示。
- **待做**：准确映射回 Markdown 起止行、原始 TeX 与转换后 TeX，并提供复制定位片段；避免把“附近文字”误当错误公式本身。

### FR-07 输出路径和模式

- 模式：讲义原文、讲义学生、讲义教师；题卡／组卷学生、教师。
- 输出：A4 PDF、系统打印、保存并打印、备用 HTML；PDF 默认写入库内 `ExamExports/`。
- 分页保留题号、题目结构、答案块与留白分段；不依赖视觉裁切掩盖布局错误。
- 仅在完成独立 PDF 渲染／分页核验后报告保存成功；打印任务提交不能等同于纸面实际打印完成。

## 4. 题库元信息与组卷（P1：本地有代码路径，但宿主验收未完）

### FR-08 YAML 元信息边界

- 普通讲义的 `==` 答案槽判断**不需要** YAML；普通讲义渲染不应因缺少 YAML 题型而失效。
- 题库对象可用 `object_type`、`question_type`/`type`、`knowledge_nodes`、`role`、`family_id`、`parent_id` 等字段支持识别、分类和结构关系。
- 元信息审计报告缺失与不一致，不得伪造 `id`、来源或题族关系。
- `question_type` 用于题型分组而不是重新解释 `==` 的括号规则。

### FR-09 文件夹组卷

- 从当前题卡所在文件夹收集可识别题卡；按**题型**或**主知识点**分组。
- 当前实现约束：文件夹至多 200 份 Markdown、单次至多 100 道有效题；不暗示已经具备全库题篮搜索。
- 多知识点题目只归入一个主要分组，避免重复出题；保留完整元信息供未来多选检索。
- 支持学生／教师试卷、题号和元信息打印字段配置、备份与诊断。

### FR-03 补充：学生填空横线宽度

学生版不得以固定四个全角空格或固定 2.2em/2.8em 代替所有填空。普通文本答案、独立数学答案及行内数学环境中的答案，应按答案的实际排版宽度生成横线；最小宽度 3em（宽度单位相对于相同版心字体）。实现必须在临时测量结束后清理所有答案内容，不向学生版 PDF/HTML 写入可恢复的原答案。不同 Obsidian 主题的字体、行内数学和超宽答案仍需真实宿主视觉验收。
