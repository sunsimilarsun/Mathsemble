# 0.2.1 扁平知识属性测试说明

日期：2026-11-05。状态：开发测试候选。安装后运行“知识点与组题工作区”；基本流程沿用[首版说明](TESTING_0.2.0.md)。

知识正文采用八字段：`id/title/subject/knowledge_nodes/teaching_tier/aliases/prerequisites/status`。写作事实源为相邻内容库的[知识点规范](../../../Markdown/数学教学/模板&规范/知识点文件规范.md)和[知识点模板](../../../Markdown/数学教学/模板&规范/知识点【模板】.md)，本仓库不保存第二份可编辑正文或模板。

- 知识页的 `teaching_tier` 可为多个等级，筛选按包含关系匹配；题卡继续使用单值。旧知识页的单值及 `level` 可兼容读取，明确的空列表不会回退读取旧值。
- `knowledge_nodes` 的共同纯文本标签在相同、非空的 `subject` 内关联；一个标签可以覆盖多篇知识。结果和题目预览显示关联知识，可直接打开并整篇加入。
- 明确的 ID、路径和真实 Wiki 目标优先定位。缺失的 Wiki 链接不会被悄悄当成标签；同名歧义继续提示。`~`、`[[~]]` 和嵌套空列表不进入检索选项。
- 属性调整会触发已保存方案的来源变化检查；重新扫描、核对后显式更新引用，再生成讲义。
