# Mathsemble 0.2.3 发布候选

讲义可在默认单栏、顺序双列和试听排版之间切换，同一外观用于预览、学生／教师 PDF、双版 PDF 与 HTML。此候选以用户测试验收通过的外观 v8 为基线；当前第 4 份候选保留 `titile`／`author` 课程属性读取，修复题卡误报和少量公式实际越界，完成本地与跨平台自动化检查，版本号仍为 0.2.3。

## 功能与修复

- 试听首页显示课程信息和学习目标，下方框内放讲义正文。教师读取 `author`，缺失、空值或仅有空白时默认“孙老师”；课题名称仅读取 `titile`（按用户指定拼写），取消 `课题名称` 和 `title` 属性回退，缺失留空。可手动调整。第 2、4 列均为 12%，课题名称列为 41%。
- 双列从左栏排到右栏，再续下一页；独立六连字符继续表示下一张纸的左栏。
- MathJax 4 下按实际正文、Callout 和列表宽度为长公式断行。先展开打印副本的折叠解答；超宽行内条件公式允许内部断行，保留原数学字级与内容。
- 修复混合文字／公式答案槽被整体转义引发的公式警告，学生版高度测量和教师版使用相同修复。
- 长讲义先集中测量、再分批排版，避免逐公式反复重排。外层和公式共用有上限的内容量预算；字体与样式单次等待仍限 15 秒，保留取消和真实溢出保护。
- 安装包工作流同步当前插件 ID `mathsemble`，避免旧名称检查错误拒绝构建。
- 修复已换行公式仍少量超宽的情况：同时检查真实左右边界和显示容器内边距，最多重新断行两次，字号和内容保持不变，取消、超时及真正不可容纳内容的报错继续有效。
- `type: 题卡` 不再与 `question_type` 误报冲突；真正的旧题型冲突仍会提示。
- 测试默认使用版本化通用模板与固定版本的本地 MathJax／字体资源，不再依赖个人内容库或 Obsidian 安装文件。

讲义源文与正式 Obsidian 安装目录未修改。本候选以已验收的 v8 隔离构建；另一个工作区正在进行的“辨析”题标变更未纳入此包。

## 安装

关闭讲义预览并停用 Mathsemble，将候选包内 `mathsemble/` 的 `main.js`、`manifest.json`、`styles.css` 同时覆盖至现有插件目录，再启用插件并重新打开预览。已有目录名可能为 `Mathsemble`，请覆盖现有目录，不要并行安装两个副本。

包内只包含三个安装文件、此说明与 MIT 许可证，不含私人讲义、学生资料或导出 PDF。
