# Mathsemble 路线图与技术债（2026-10-23）

本路线图明确 **已在本地 v0.1.9 安装包中存在的功能** 和 **尚需开发／验收的功能**。它不是“全部已完成”的发布公告。

## 当前基线：v0.1.9 实验包

| 范围 | 状态 | 说明 |
| --- | --- | --- |
| 单份 Markdown 学生／教师双版 | 本地已实现、宿主待验收 | 题卡、长讲义与文件夹组卷路径 |
| `+/-` 教师专用、无标记双版共用 | 本地已实现、宿主待验收 | 不区分 Callout 名称，学生替换等高留白 |
| 原版渲染折叠 Callout | 本地已修复、宿主待验收 | 只展开导出临时 DOM，不修改原文 |

## P0｜先让现有 PDF 工作流可靠

1. **双版回归**：同一源 Markdown 的原文／学生／教师版；覆盖 0、1、多个教师专用 Callout；同时有无标记的 `answer` 和 `student-note`。
2. **留白复验**：100% 高度与教师块外高度匹配；页面分割不减少有效书写面积；支持可接受的尾部空白页。
3. **打印端兜底**：预览、导出前、独立打印窗口应用同一异常分级；新的图片或公式失败不得借旧授权逃过检查。
4. **完整文档校验**：MathJax、SVG/TikZ、Markdown 表格、原生 HTML、不同主题、不同字体、长连等式与复杂嵌套。
5. **恢复可维护源码**：将 v0.1.9 的实验补丁合并到 src，测试、构建、manifest 同步，仓库建立可复现的本地打包流程。

**通过条件**：至少一个复杂长讲义和一套混合题型试卷，完成真实 Obsidian 两版 PDF 逐页复核，保留页数、截图、留白高度日志和异常清单；关键阻断用例必须全部通过。

## P1｜诊断可定位，组卷可复用

1. MathJax 失败定位到**源文件行号／原始公式片段／转换后片段**，并能在一个详情面板中查看所有警告。
2. 降低数学与 Markdown 混合语法的误解析；尤其是 `\text{...}` 内再使用 `$` 或 `==` 的歧义。
3. 题卡列表／搜索／筛选／题篮，支持手工排序、题型配额、难度、知识点及教学角色。
4. 元信息规范：`knowledge_nodes`、`family_id`、`parent_id` 等来源明确、可审核，不必为普通讲义强制写 YAML。
5. 长讲义分页性能与内存占用优化，布局报告和异常信息可导出为 JSON。

## P2｜Math Teaching Workbench 深度整合

1. KnowledgeItem／题卡／题族联合组讲义：先选知识点与教学目标，再选例题、变式、练习、检测。
2. 适配课堂讲义、学生卷、教师卷、检测卷和答案册，采用统一的双版本规则。
3. 模板化课程结构、元信息映射、可重现构建与审校记录。
4. 在 P0 宿主和发布验收通过后，再考虑 Obsidian 社区发布与独立分发。

## 2026-10-23 填空宽度修复与验收

- **实验包已更新**：学生填空采用原答案临时渲染测宽，最小 3em；学生输出不包含原答案文本。
- **已测**：中文、英文字体宽度；MathJax 短公式、分式、区间答案；转换后的学生版隐去答案，选择题规则不变。
- **待验收**：Windows/macOS Obsidian 不同主题下阅读视图、实时预览和学生 A4 PDF 同槽宽度对照；检查超宽公式拦截、PDF 分页和教师专用块等高留白。


## 2026-10-23 数学 Callout 样式整合

- **本地实验实现**：八类数学 Callout 内置语义配色；`answer` 深橙、`scaffold` 淡紫，`solution` 兼容；普通 Markdown 例题无需 `example` Callout。
- **隔离与保护**：默认 Obsidian 阅读视图、实时预览、打印/测量 DOM 均直接匹配八类语义 Callout（无 YAML 亦可）；不覆盖全局 `mark`、`strong`、`example`，不修改显隐/等高留白判定或填空宽度；打印 CSS 同步嵌入 `main.js` 独立 HTML 输出。
- **局部测试已通过**：JavaScript 语法、36 个教师专用块对应 36 个学生留白槽、Chromium 11 类 Callout 的配色及几何；示例 Callout 高度变化 0px。
- **P0 待验收**：真实 Obsidian 多主题及用户 CSS Snippets、长讲义学生/教师 A4 PDF 分页、跨页等高留白和 MathJax。
- **P1 可选功能**：数学彩色/简洁黑白/跟随 Obsidian 的外观切换；如需求明确再支持自定义颜色。


## v0.1.9 普通阅读视图主题修复（2026-10-23）

修复上一版 Callout 配色依赖 `mwb-math-material`、`mwb-answer-note` 等识别类导致普通笔记不生效的问题。现直接覆盖 Obsidian **阅读视图、实时预览**和 Mathsemble A4 预览/打印。只有八类核心 Callout 加旧版 `solution` 受到配色影响；`example` 保持普通外观。无 YAML 亦可应用，且不改写 `mark`、`strong`，不改变 `[!类型]+/-` 教师专用学生等高留白及答案槽语义。已经通过无 YAML 普通阅读、实时预览、打印 DOM 的 Chromium 模拟测试及 36 个留白槽回归；真实 Obsidian 宿主及长 PDF 仍待验收。
