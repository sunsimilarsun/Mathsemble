0.4.0 在 0.3.1 基础上整合 P2、相似题和引用式讲义。版本变化见 [0.4.0 发布说明](RELEASE_NOTES_0.4.0.md)，各功能的验证范围见[功能矩阵](FEATURE_MATRIX.md)，题库书写约定见 [Markdown 规范](MARKDOWN_SPEC.md)。

## 已发布基础：选材、编排与可靠输出

0.3.0 已有跨目录搜索、题目与知识混编、条件抽题、独立预览编排、分区整体排序、课程与默认排版、方案保存、临时 A4，以及默认／双列／试听外观的学生和教师输出。源文仍是内容事实源；来源变化须核对，不自动接受新内容。

P1 的三项能力已在 0.3.0 发布，不再列为待开发：

- **媒体冻结与归档**：测量前固定资源，同会话双版复用，本地 SHA-256 变化拦截，持久导出记录及可选教师材料归档。
- **配额组卷**：多行条件、全局分配、锁定与重抽、已有题显式归属、题族上限、独立蓝图与运行记录。
- **题族操作**：精确题族筛选、显式母题关系诊断、受当前筛选及已知配额约束的同族换题。

0.3.0 的 Windows 分阶段宿主、截图和 PDF 验收，以及 811 项自动化检查，见 [0.3.0 验证](TESTING_0.3.0.md)和 [P0／P1 实施验收](research/question-banks-2026-11-17/IMPLEMENTATION_ACCEPTANCE.md)。这些结论只覆盖当时对应的源码、环境和样例，不扩展为 P2 或跨平台全覆盖。

## 0.4.0 整合的 P2 功能

| 工作包 | 实现范围 | 完成边界 |
| --- | --- | --- |
| 实际使用账本 | 教师明确登记讲授／布置；班级／课程隔离、当时原文与版本、幂等动作、撤销更正、近期使用筛选 | 导出、保存和投影不算实际使用；部分使用保留范围；撤销不删除历史，损坏账本不能静默覆盖 |
| 题库诊断与待入库 | 集中查看字段、身份、资源和疑似重复问题；Markdown／明确 JSON profile 原件与候选暂存 | 先核对损耗和映射，再确认创建；不自动改号、合并或覆盖。撤销保留用户后改、替换及归属不明的文件 |
| 稳定片段与卷内分值 | 显式小问／知识小节、整题和完整小问分值；按需使用 v4 | 无锚点旧卡继续整篇使用；缺失锚点或依赖阻断；旧方案启用新字段必须另存，0.3.0 不读 v4 |
| 可校验材料包 | 封装当前方案、源文和已捕获资源，经暂存确认回导；原字节与新映射分别保留 | 未捕获依赖如实标为 `partial`；历史旁车内部路径不冒充当前可执行记录；不承诺通用 QTI 或未知格式 |
| 逐题投影 | 当前编排大字号展示、翻页、当前项揭示及换页重置 | 来源或编排变化后重新生成；不修改题卡，不生成教学事实或学生掌握判断 |

阶段构建和 Windows Obsidian 实测见 [P2 实施记录](P2_IMPLEMENTATION.md)。稳定片段语法、答案和图像归属、v4 另存规则见[片段契约](ASSEMBLY_FRAGMENTS.md)。

方案继续读取 v1／v2／v3；未使用新增字段时仍可保存 v3。原题卡不增加必填字段，也不批量迁移。使用历史、入库原件／映射／日志、配额运行记录及导出归档是持久资产，须随题库备份，不作缓存清理；其中可能含完整教师原文和答案，分发范围见[隐私说明](PRIVACY.md)。

## 持续补齐的可靠性范围

1. 对每次增量完成目标提交的干净构建、故障回归及真实 Windows Obsidian 验收；记录源码摘要、宿主版本、主题、输出和实际检查范围。
2. 单独安排 macOS、实体打印及更多第三方主题／插件组合；不能用 Windows 或 Chromium 模拟结果代替。
3. 继续核对原生公式内部答案槽、复杂 HTML／Markdown、脚注、嵌入和 TikZ。未覆盖或不满足结构契约的内容明确诊断，不静默截断。
4. 保持来源变化、取消、未知写入结果、资源预算、清理和恢复的回归；已写文件的事实与后续操作失败分开记录。
5. 随新增模板和真实失败样例维护回归，保留唯一可维护源码与可重建安装产物，不从生成文件恢复业务逻辑。

## 后续需求触发的能力

OCR／Word 导入、DOCX／QTI 互通、学生作答 Attempt、自动评分、AI 生成、学生端和云同步不属于本轮 P2。需要明确的使用者、目标格式、协作场景和验收样例后再立项。多篇讲义导出队列、更多打印配色和其他课堂交互按实际需求排序，不把路线图示例当作已承诺交付。

## 发布条件

- 目标提交通过干净构建、全量测试、模板检查和发布预检，浏览器用例无跳过。
- 按 [Obsidian 宿主验收](OBSIDIAN_HOST_ACCEPTANCE.md)记录本轮真实结果与未覆盖边界，核对学生输出和完整 PDF；历史通过记录不替代新功能验收。
- 原题卡、旧方案读取、v4 另存、使用记录与入库撤销等兼容和故障路径有可追溯检查；保留升级前插件、方案及持久旁车备份。
- 版本、标签、发布说明和三个安装文件对应同一受测提交，发布步骤见[发布指引](PUBLISHING.md)。
- 社区目录审核／上架状态以实际审核结果为准。
